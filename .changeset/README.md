# Changesets

이 폴더는 [Changesets](https://github.com/changesets/changesets)가 관리합니다.

기능 PR에는 changeset을 포함하세요:

```bash
pnpm changeset
```

변경 종류(major/minor/patch)와 한 줄 설명을 입력합니다.
**이 설명이 곧 릴리스 노트이자 개인 기여 기록입니다** — "fix bug" 대신
`record: 카세트 매칭 시 타임스탬프 필드를 비교 대상에서 제외` 수준으로 쓰세요.

자세한 규칙은 [CONTRIBUTING.md](../CONTRIBUTING.md) §7 참조.
