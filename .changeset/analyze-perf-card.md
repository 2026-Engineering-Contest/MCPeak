Analyze 화면의 성능 효율성 카드가 `mcpeak perf` 와 연결됩니다. 카드를 눌러 연 상세에서 고른 서버에 딸린 테스트 명세와 반복 횟수를 고르고, 시작 전 고지(케이스를 실제로 반복 호출하고 쓰기 도구도 포함되며 격리 없이 이 컴퓨터에서 서버를 띄운다)를 본 뒤 측정을 시작합니다. 성능 측정은 "분석하기" 에 들지 않고, 원격(HTTP) 서버는 측정할 수 없습니다. 결과는 카드에 병렬화로 줄일 수 있는 시간과 측정·미측정·진단 칩으로, 상세에 개선 지점·케이스별 응답 시간·미측정 케이스·이 측정의 한계로 보입니다. 서버 API 에 `POST /api/analyze/perf` 와 `GET /api/analyze/perf/<runId>` 가 늘어납니다.
