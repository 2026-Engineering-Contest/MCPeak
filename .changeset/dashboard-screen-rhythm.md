대시보드 화면의 위계를 다시 잡습니다(#459).

- **제목이 한 번만 나옵니다.** 앱 위의 헤더 스트립(`Test` 한 단어)을 걷고 화면 제목을 본문
  `PageHeader` 한 곳에 `text-display` 크기로 둡니다.
- **테마는 Light · Dark 두 버튼 토글입니다.** 본문 오른쪽 위에 해 · 달 아이콘과 함께 두 선택지가
  나란히 보이고 지금 켜진 쪽이 눌려 있습니다.
- **로고가 바뀝니다.** 어두운 둥근 사각형 위로 보라색 선이 오르고 끝에 초록 체크가 붙습니다.
  사이드바와 터미널 카드 머리가 같은 로고를 씁니다. 로고 색 토큰은 테마를 타지 않습니다.
- **사이드바가 바뀝니다.** 부제 `MCP Dashboard`, 아래쪽에 Settings(준비 중 화면)와 Help & Docs
  (README 를 새 탭으로)가 생깁니다. 하단의 서버 주소는 뺐습니다.
- **실행 화면은 터미널이 주인공입니다.** 머리(제목 · 스위트 · 서버 · Run ID 복사 · 상태와 할 일 ·
  통과 · 실패 · 미실행 작은 칸), 터미널 카드(수신 표시 · 줄 수 · 지우기 · 복사), 그리고 터미널
  **아래** 따로 선 질문 카드입니다. 세 칸은 runner 요약 줄이 온 뒤에만 채웁니다(ADR-0096).
  진행률 막대는 두지 않습니다.
- **터미널이 440px 아래로 줄지 않습니다.** 창이 낮으면 터미널을 누르는 대신 화면이 스크롤합니다.
- **빈 상태가 다음 행동 링크를 줍니다.** Runs · Replay · Repair 의 빈 목록, 그리고 없는 run
  화면이 해당 화면으로 가는 링크를 붙입니다. 없는 run 에는 빈 터미널을 더 그리지 않습니다.
- 서버 후보 행은 이름을 굵게 두고 출처 · 경로 · 명령을 한 단 약하게 내립니다.
- Runs 목록에서 경로가 길면 상태 뱃지가 카드 밖으로 밀려 잘리던 문제를 고칩니다.
