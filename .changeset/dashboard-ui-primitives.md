대시보드 버튼과 카드를 공용 컴포넌트로 모읍니다. 흩어져 있던 버튼 19곳(프라이머리 10 · 보조 9)이
`Button` 을, 카드 4곳이 `Card` 를 씁니다.

**키보드로 쓸 수 있게 됩니다.** 예전에는 `focus-visible` 스타일이 저장소 전체에 하나도 없어
지금 어느 버튼에 있는지가 브라우저 기본 아웃라인에만 달려 있었습니다. 이제 세 variant 모두
토큰 색 포커스 링을 갖습니다. 프라이머리 버튼에 hover·active 상태가 처음 생기고, 비활성 버튼은
흐려지는 것에 더해 커서로도 눌리지 않음을 알립니다.

카드에 그림자가 생겨 페이지 배경과 구분됩니다. 버튼 모서리는 6px 로 통일됩니다.
