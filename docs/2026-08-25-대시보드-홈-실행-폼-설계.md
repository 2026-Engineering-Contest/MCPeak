# 대시보드 홈 실행 폼 설계 (2026-08-25)

상위 문서: `docs/2026-08-19-대시보드-설계.md`(아키텍처), `docs/2026-08-19-대시보드-UI-설계.md`
(이하 "UI 설계"). 이 문서는 UI 설계 §5-1 Home 의 실행 폼을 대체한다. 다른 화면은 건드리지
않는다. 시각 확정본은 아티팩트에 있다:
https://claude.ai/code/artifact/f3368324-e1e8-4ebf-ae92-1be762bd1403 (화면 4장).
같은 HTML 이 `docs/mockups/2026-08-25-홈-실행-폼/home-server-picker.html` 에 있고, 정적
캡처(다크, 1440 폭 뷰포트 JPG 4장)가 같은 디렉터리에 `01-후보-있음` ~ `04-테스트-옵션` 으로
있다.
목업과 이 문서가 어긋나면 **이 문서가 우선**한다. 어긋나는 곳은 §8 에 적었다.

## 1. 배경

홈의 `실행` 버튼을 누르면 서버 실행 방법, 스크립트 경로, 인자를 스위트마다 매번 손으로
적어야 한다. 같은 서버를 두 번째 실행할 때도 처음과 똑같이 적는다. 그리고 `mcpeak test` 의
옵션 중 대시보드가 노출하는 것은 `--command`·`--arg`·External 세션 둘뿐이라, JUnit 리포트나
결정론 검사는 CLI 로 돌아가야 쓸 수 있다. UI 설계 §1-2 는 "명령어를 몰라도 쓸 수 있어야
한다"를 원칙으로 두었는데, 홈 실행 폼이 그 원칙을 가장 못 지키고 있었다.

`StepServer` 의 힌트 문구가 이미 "프로젝트 스캔 API 없음"이라 적고 있고, Home 은
`recentCommands={[]}` 로 최근값 기능을 꺼 둔 채다. 처음부터 비워 둔 자리를 채우는 일이다.

## 2. 목표

1. 스위트의 `실행` 을 누르면 **서버를 고르기만** 하면 되게 한다. 프로젝트에서 찾은 후보와
   이 브라우저의 지난 실행값이 선택지로 나오고, 직접 입력은 마지막 갈래로 남는다.
2. `mcpeak test` 옵션을 GUI 컨트롤로 노출한다. 프론트가 argv 를 조립하고, 조립된 CLI 명령
   전문을 항상 보여준다(UI 설계 §1-2).
3. CLI 가 거절하는 조합은 폼에서 만들 수 없게 한다. 서버에 보내고 거절당하는 왕복을 없앤다.
4. 지금까지 돌던 실행의 argv 는 한 토큰도 바뀌지 않는다. 기본값으로 시작하면 지금과 같은
   명령이 나간다.

## 3. 비범위

- Generate 마법사의 1단계(`StepServer`)에 서버 후보 목록을 붙이는 일. 같은 API 를 쓸 수
  있지만 이 문서는 홈만 다룬다.
- 스위트 JSON 에 서버 명령을 넣는 일. `runner` 스키마 변경이라 다른 오너 패키지다.
- 실행 이력(`RunSummary`)에 argv 를 남겨 "같은 설정으로 다시" 를 만드는 일. 지난 실행값은
  브라우저 `localStorage` 로 충분하고, 서버 이력은 재시작하면 사라진다(상위 설계 비범위).
- 서버를 `--help` 로 띄워 인자 목록을 얻는 일. ADR-0079.
- `--json`. 대시보드는 터미널 출력을 SSE 로 흘리는 구조라 JSON 출력은 화면과 맞지 않는다.
- `.mcp.json` 항목의 `env`. 대시보드는 자식 프로세스 환경변수를 주입하는 통로가 없다.
  항목은 목록에 나오되 `env` 는 무시하고, 그 사실을 후보 행에 적는다(§5-2).

## 4. 결정 요약

| 항목 | 결정 |
|---|---|
| 서버 후보 출처 | 루트 아래 `.mcp.json` 의 `mcpServers`, `package.json` 의 `bin`. 둘 다 파일을 읽기만 한다. 서버를 실행해 알아내지 않는다(ADR-0079) |
| 후보 API | `GET /api/servers` 신설. `GET /api/suites` 와 같은 스캔 규칙(제외 디렉터리, 루트 밖 차단, 실패 항목 조용히 제외) |
| 지난 실행값 | 브라우저 `localStorage`, 스위트 경로별 1건. 서버 이력에 의존하지 않는다 |
| 최근 명령 | Generate 마법사의 `localStorage` 목록을 Home 과 공유한다. 저장 키는 기존 값을 유지한다 |
| 테스트 옵션 | `mcpeak test` 옵션 중 `--json` 을 뺀 전부를 접이식 섹션으로 노출. 기본값이면 argv 에 붙이지 않는다 |
| HTTP 대상 | `--url`·`--header-env` 를 폼에 노출한다. 대시보드 `wiring.ts` 가 `connectHttp`·`readEnv` 를 배선하지 않아 지금은 `--url` 이 서버에서 멈춘다. 이 배선을 함께 넣는다 |
| 실행 버튼 | 폼이 열려 있으면 같은 자리의 버튼이 `닫기` 가 된다. 한 번에 한 스위트만 열린다 |
| 조합 제약 | CLI `parseTestCommand` 의 거절 규칙을 폼이 선반영한다. 판정 함수는 `buildTestArgv` 하나이고, 시작 버튼 비활성과 제출이 같은 함수를 쓴다 |

기각한 대안은 ADR-0079 과 §8 에 있다.

## 5. 화면 사양

### 5-1. 스위트 행과 버튼

- 행 우측 버튼은 폼이 닫혀 있으면 `실행`, 열려 있으면 `닫기`. 같은 버튼 요소이며 라벨과
  `aria-expanded` 만 바뀐다.
- 다른 스위트의 `실행` 을 누르면 열려 있던 폼은 닫히고 그 스위트의 폼이 열린다(현재
  `promptFor` 동작 유지).
- 폼을 열 때마다 서버 선택·인자·옵션은 §5-5 의 규칙으로 다시 채운다. External 세션은
  항상 `사용 안 함` 으로 되돌린다(녹화 경로를 재사용하면 CLI 가 덮어쓰기를 거절한다, #290).

### 5-2. 서버 선택

폼 맨 위. 라벨 `서버`, 우측에 `프로젝트에서 N개 찾음`. 라디오 카드 목록이며 항목 순서는
고정이다.

1. 지난 실행(있을 때만). 이름 `지난 실행`, 부제는 저장된 명령 전문, 출처 배지 `이 브라우저`.
   스캔 후보와 명령·인자가 완전히 같으면 이 항목을 만들지 않고 그 후보를 선택한다.
2. 스캔 후보. `GET /api/servers` 순서 그대로. 이름은 설정의 키, 부제는 명령 전문(mono),
   출처 배지는 `.mcp.json` 또는 `package.json` 과 파일 상대경로. `.mcp.json` 항목에 `env`
   가 있으면 부제 아래 `env 는 대시보드가 넘기지 못합니다. 셸에서 미리 내보내세요.` 를 적는다.
3. `직접 입력`. 부제 `목록에 없는 서버를 실행 방법·스크립트·인자로 적습니다.`, 배지 `수동`.

선택 시 동작:

- 후보나 지난 실행을 고르면 `command` 와 `args` 가 그 값으로 바뀐다. `args` 는 아래
  `서버 인자` 칩으로 그대로 보이고, 빼거나 더할 수 있다. 편집해도 선택은 유지된다.
- `직접 입력` 을 고르면 그 아래로 현재 `StepServer`(실행 방법 세그먼트, 서버 스크립트,
  서버 인자)가 펼쳐진다. `recentCommands` 에는 공유 최근 명령 목록을 준다.
- 후보가 0개이고 지난 실행도 없으면 라디오 목록 대신 안내 상자 하나를 두고 `직접 입력` 이
  펼쳐진 상태로 시작한다. 안내 문구는 탐색 루트(`GET /api/meta` 의 `root`)와 해결 방법을
  담는다:

  ```
  <root> 아래에서 .mcp.json 이나 package.json 의 bin 을 찾지 못했습니다.
  아래에 직접 적거나, 루트에 .mcp.json 을 두면 다음부터 목록에 나타납니다.
  ```

  `root` 를 못 받았으면(메타 실패) 경로 없이 나머지 문장만 적는다(#296 과 같은 처리).

### 5-3. 서버 인자

라벨 `서버 인자`. 후보를 골랐을 때 우측 부제 `선택한 서버의 인자를 가져왔습니다. 고칠 수
있습니다.`. 칩 목록 + `인자 하나씩 추가` 입력 + `추가` 버튼(현재 `StepServer` 의 인자
부분과 같은 컴포넌트). 직접 입력 갈래에서는 `StepServer` 안의 인자 입력을 쓰고 이 블록은
그리지 않는다(같은 인자 입력이 두 번 보이지 않게).

HTTP 대상(§5-4)을 고르면 이 블록은 비활성이 되고 힌트 `원격 서버에는 띄울 프로세스가
없어 인자를 넘기지 않습니다.` 를 적는다. 값은 지우지 않고 argv 에서만 뺀다(다시 stdio 로
돌아오면 그대로 살아난다).

### 5-4. External 세션

현재 구현 그대로(`사용 안 함` / `외부 호출 녹화` / `녹화본 재생` 세그먼트 + 경로 입력).
두 가지 비활성 규칙을 더한다.

- HTTP 대상이면 세그먼트 전체 비활성, 힌트 `External 세션은 우리가 띄운 프로세스에만
  붙습니다. 원격 서버에는 그 프로세스가 없습니다.`
- 결정론 검사가 켜져 있으면 `녹화`·`재생` 비활성, 힌트 `결정론 검사는 서버에 2회
  연결하지만 세션은 연결 하나에 묶여 있어 함께 쓸 수 없습니다.`

### 5-5. 테스트 옵션

External 세션 아래, 접이식 섹션. 머리줄은 `▸ 테스트 옵션` + 우측 요약. 요약은 바꾼
옵션이 없으면 `기본값 · 바꾼 것 없음`, 있으면 `N개 바꿈`. 펼침 여부는 폼을 열 때 접힘으로
시작한다.

세 묶음으로 나눈다. 묶음 제목은 소문자 대문자 라벨(`접속`, `검사`, `결과 파일`).

**접속**

- 세그먼트 `stdio (위 서버 명령)` / `HTTP URL`. 기본 stdio.
- HTTP 를 고르면 그 아래 `URL` 입력(`--url`)과 `헤더 환경변수` 칩 목록(`--header-env`)이
  나타난다. 칩 값은 `<헤더이름>=<환경변수이름>` 한 줄이며 입력 힌트는
  `예: Authorization=MCP_TOKEN. 값이 아니라 환경변수 이름을 적습니다.`. 형식 검사는
  `=` 가 있고 양쪽이 비어 있지 않은지만 본다. 세부 검사는 CLI 가 하고 그 문장이 실행 뷰에
  그대로 나온다.
- HTTP 를 고르면 서버 선택(§5-2)은 그대로 보이되 비활성이고, 힌트 `원격 서버에 붙습니다.
  위 서버 명령은 쓰이지 않습니다.` 를 적는다.

**검사**

- 체크박스 `결정론 검사` (`--determinism`). 설명 `스위트를 2회 실행해 결과를 대조합니다.`
  세션이 켜져 있으면 비활성, 힌트는 §5-4 와 같은 문장.
- 텍스트 입력 `초기화 명령` (`--reset-cmd`). 설명 `회차마다 실행 전에 서버 상태를 되돌리는
  셸 명령입니다. 결정론 검사와 함께 쓰면 초기 상태 복원이 확인됩니다.` 비우면 보내지 않는다.
- 숫자 입력 `서버 stderr 줄 수` (`--stderr-lines`). 설명 `실패 시 함께 보여줄 서버 로그 줄
  수. 기본 20.` 비우면 보내지 않는다. `0` 이상 정수만 받는다. HTTP 대상이면 비활성, 힌트
  `원격 서버에는 stderr 를 읽을 프로세스가 없습니다.`

**결과 파일**

- 텍스트 입력 `JUnit 리포트` (`--junit`). 설명 `비우면 만들지 않습니다. 디렉터리는 있어야
  합니다.`
- 텍스트 입력 `Repair 번들` (`--repair-bundle`). 설명 `실패를 Repair 화면에서 고칠 수 있게
  묶어 둡니다.`

### 5-6. 실행될 명령

`실행될 명령` 상자는 `mcpeak test` 로 시작하는 argv 전문을 mono 로 보여준다. 값은
`buildTestArgv` 결과에 `mcpeak test` 를 앞에 붙여 공백으로 이은 것이다. 공백이 든 토큰은
큰따옴표로 감싼다(표시 전용, 서버에는 배열로 간다). 조립이 실패하면 상자에 그 사유 문장을
붉게 적고 시작 버튼을 비활성으로 둔다.

### 5-7. 실행 시작 이후

- `POST /api/runs {flow:"test", argv}` 후 `#/runs/:id` 로 이동(현재와 같다).
- 이동 전에 지난 실행값을 저장한다(§6-3). 직접 입력 갈래였으면 최근 명령 목록에도 서버
  스크립트를 저장한다(§6-4).
- 저장 실패는 무시한다. 실행은 이미 시작됐다(Generate 마법사와 같은 이유).

## 6. 계약

### 6-1. `GET /api/servers`

`packages/dashboard/src/api-types.ts` 에 추가한다.

```ts
/** GET /api/servers — 서버 후보 한 건. 파일을 읽어 만들며 서버를 실행하지 않는다(ADR-0079). */
export interface ServerCandidate {
  /** 같은 스캔이면 같은 값. `${source}:${path}:${name}`. */
  readonly id: string;
  /** `.mcp.json` 의 mcpServers 키 또는 package.json 의 bin 키. */
  readonly name: string;
  readonly command: string;
  readonly args: readonly string[];
  readonly source: "mcp-config" | "package-bin";
  /** 후보를 읽은 파일의 루트 기준 상대경로(`/` 구분). */
  readonly path: string;
  /** `.mcp.json` 항목에 env 가 있었는지. 대시보드는 넘기지 못하므로 화면이 알린다. */
  readonly hasEnv: boolean;
}
```

스캔 규칙(`packages/dashboard/src/server/files.ts` 에 `listServerCandidates(root)`):

- `walkJsonFiles` 와 같은 순회(제외 디렉터리 `node_modules`, `.git`, `dist`). 파일명이
  정확히 `.mcp.json` 또는 `package.json` 인 것만 연다.
- `.mcp.json`: `mcpServers` 가 객체일 때 각 키에 대해 `command` 가 비어 있지 않은 문자열이면
  후보. `args` 는 문자열 배열이면 그대로, 없으면 `[]`, 그 밖의 형은 항목 제외. `env` 가
  객체이고 키가 하나라도 있으면 `hasEnv: true`. `url` 만 있는 항목(원격)은 제외한다.
- `package.json`: `bin` 이 문자열이면 이름은 `name` 필드(없으면 파일이 든 디렉터리 이름),
  객체면 각 키. 값은 그 package.json 이 있는 디렉터리 기준 경로다. `bin` 이 없으면 후보 없음.
  **무엇으로 띄울지는 확장자로 가른다(H0 결정).** 루트 기준 상대경로(`/` 구분)를 `p` 라 할 때,
  `p` 가 `.js`·`.mjs`·`.cjs` 로 끝나면 `command: "node"`, `args: [p]` 이고, 그 밖은
  `command: p`, `args: []` 로 두어 파일 자체를 실행 파일로 본다. npm 의 `bin` 은 JavaScript
  파일로 제한되지 않아 셸 스크립트나 다른 런타임의 진입점도 올 수 있고, 그것을 `node` 로
  띄우면 잘못 실행되기 때문이다(PR #359 리뷰). 확장자는 파일을 열지 않고 경로만 보고
  판정하므로 ADR-0079 를 지킨다.
- 정렬은 `path`, 그 다음 `name` 의 `localeCompare`. 파일마다 항목 순서가 JSON 키 순서에
  의존하지 않게 한다(결정론).
- JSON 파싱 실패, 읽기 실패, 형 불일치는 조용히 제외한다(`listSuites` 와 같은 정책).

라우트: `GET /api/servers` → `200 ServerCandidate[]`. `routes.ts` 의 `/api/suites` 바로
아래에 둔다.

### 6-2. `buildTestArgv` 확장

`packages/dashboard/web/src/build-test-argv.ts`. 기존 `TestForm` 필드는 유지하고
`options` 를 더한다. **기본값 폼의 결과는 지금과 바이트 단위로 같다.**

```ts
export type Transport = "stdio" | "http";

export interface TestOptions {
  readonly transport: Transport;
  /** transport 가 http 일 때만 쓴다. */
  readonly url: string;
  /** `<헤더이름>=<환경변수이름>` 문자열. transport 가 http 일 때만 쓴다. */
  readonly headerEnvs: readonly string[];
  readonly determinism: boolean;
  /** 빈 문자열 = 미지정(CLI 기본 20). */
  readonly stderrLines: string;
  readonly junitPath: string;
  readonly repairBundlePath: string;
  readonly resetCmd: string;
}

export const DEFAULT_TEST_OPTIONS: TestOptions = {
  transport: "stdio",
  url: "",
  headerEnvs: [],
  determinism: false,
  stderrLines: "",
  junitPath: "",
  repairBundlePath: "",
  resetCmd: "",
};

export interface TestForm {
  readonly suitePath: string;
  readonly command: string;
  readonly args: readonly string[];
  readonly sessionMode: SessionMode;
  readonly sessionPath: string;
  readonly options: TestOptions;
}
```

argv 순서(고정):

```
<suitePath>
stdio: --command <command> (--arg <a>)*
http : --url <url> (--header-env <h>)*
(--record-session|--session) <sessionPath>       sessionMode 가 off 가 아닐 때
--determinism                                   determinism 이 true 일 때
--stderr-lines <n>                              stderrLines 가 비어 있지 않을 때
--junit <path>                                  junitPath 가 비어 있지 않을 때(trim)
--repair-bundle <path>                          repairBundlePath 가 비어 있지 않을 때(trim)
--reset-cmd <cmd>                               resetCmd 가 비어 있지 않을 때(trim)
```

거절 규칙과 문장(throw 메시지, 시작 버튼 비활성 사유로도 쓴다). CLI 문장과 같은 뜻이되
폼에서 무엇을 고치면 되는지를 말한다.

| 조건 | 문장 |
|---|---|
| stdio 이고 `command === ""` | `서버를 고르거나 실행 명령을 입력하세요.` |
| http 이고 `url.trim() === ""` | `URL 을 입력하세요.` |
| http 이고 `headerEnvs` 중 `=` 가 없거나 한쪽이 빈 것 | `헤더 환경변수는 <헤더이름>=<환경변수이름> 형식이어야 합니다: '<값>'` |
| http 이고 `sessionMode !== "off"` | `External 세션은 HTTP 대상과 함께 쓸 수 없습니다. 접속을 stdio 로 바꾸거나 세션을 끄세요.` |
| http 이고 `stderrLines !== ""` | `서버 stderr 줄 수는 HTTP 대상에 쓸 수 없습니다. 비워 두세요.` |
| `sessionMode !== "off"` 이고 `sessionPath === ""` | `세션 파일 경로를 입력하세요.` (기존) |
| `determinism` 이고 `sessionMode !== "off"` | `결정론 검사는 External 세션과 함께 쓸 수 없습니다. 둘 중 하나를 끄세요.` |
| `stderrLines` 가 `/^\d+$/` 가 아님 | `서버 stderr 줄 수는 0 이상의 정수여야 합니다.` |

http 에서 `args` 는 argv 에 넣지 않는다(거절이 아니라 무시. §5-3 에서 값을 지우지 않기로
했으므로 여기서 걸러야 CLI 의 `--arg 는 --url 과 함께 쓸 수 없습니다` 에 걸리지 않는다).

### 6-3. 지난 실행값 (`localStorage`)

`packages/dashboard/web/src/last-run.ts` 신설.

```ts
export interface LastRun {
  readonly command: string;
  readonly args: readonly string[];
  readonly options: TestOptions;
}
const KEY = "mcpeak-home-last-run";   // Record<suitePath, LastRun>

export function readLastRun(suitePath: string): LastRun | null;
export function saveLastRun(suitePath: string, run: LastRun): void;
```

- 저장은 실행 시작 직후, 스위트 경로를 키로 덮어쓴다. 세션 모드·경로는 저장하지 않는다.
- 읽기는 형이 어긋나면 `null`(문자열 아닌 `command`, 배열 아닌 `args`, 객체 아닌
  `options`). `options` 는 `DEFAULT_TEST_OPTIONS` 위에 얹어 빠진 키를 메운다.
- 저장·읽기의 예외는 삼킨다(`theme.ts` 와 같은 이유. `localStorage` 가 없거나 막힌 환경).

### 6-5. `wiring.ts` 의 HTTP 배선

`executeTest` 의 정상 경로 의존성에 두 필드를 더한다.

```ts
connectHttp: core.connectHttp,
readEnv: (name) => process.env[name],
```

런타임 의존성 로드 실패 경로는 지금처럼 두 필드를 비워 둔다(CLI 가 "무엇이 없는지" 를
말하고 멈춘다). `readEnv` 가 `process` 를 직접 읽는 것은 대시보드 서버 프로세스의 일이며
CLI 코드가 아니다(ADR-0013 의 주입 지점 그대로).

### 6-6. Home 상태 모델

```ts
type ServerChoice =
  | { kind: "candidate"; id: string }
  | { kind: "last-run" }
  | { kind: "manual" };
```

- `choice`, `command`, `args`, `method`, `target`(직접 입력용), `sessionMode`,
  `sessionPath`, `options`, `optionsOpen`.
- `command`·`args` 의 유효값은 갈래별로 구한다: `candidate`/`last-run` 은 상태의
  `command`·`args`, `manual` 은 `splitCommand(method, target)` + `args`.
- 폼을 열 때의 초기 선택: 지난 실행이 있으면 `last-run`(단, 스캔 후보와 같으면 그
  후보), 없으면 첫 후보, 후보도 없으면 `manual`. `options` 는 지난 실행의 것, 없으면
  `DEFAULT_TEST_OPTIONS`.

## 8. 임의 판단 기록

- **`--reset-cmd` 는 Repair 번들에 종속시키지 않는다.** 목업(화면 4)은 번들 지정 전까지
  잠갔지만, CLI 에서 이 옵션은 결정론 검사의 회차 전 초기화 훅이며(ADR-0023) 번들과 무관하다.
  문서가 목업을 이긴다.
- `claude_desktop_config.json` 은 후보 출처에서 뺐다. 프로젝트 루트 밖(사용자 홈)에 있어
  "루트 밖 접근 차단" 원칙과 맞지 않는다.
- `package.json` 의 `scripts.start` 는 후보 출처에서 뺐다. 셸 문자열을 공백으로 쪼개는
  일이라 #223 이 없앤 문제를 되살린다. `bin` 은 경로 하나라 분해가 없다.
- 라디오 카드로 그린다. 후보가 보통 1~4개라 펼쳐 놓는 편이 명령 전문 비교가 쉽다. 5개를
  넘는 경우의 접기는 비범위다.
- 폼을 열 때 External 세션은 늘 끄고 시작한다. 지난 실행값에 세션을 포함하지 않는 이유는
  녹화 경로 재사용이 CLI 거절로 끝나기 때문이다(#290).
- `--json` 을 빼고, `--name`·`--with`·`--db-path`·`--port` 는 `test` 옵션이 아니라
  주석 예시라 처음부터 대상이 아니다.
