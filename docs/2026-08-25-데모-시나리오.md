체크리스트. 하나라도 빠지면 라이브 장면이 깨진다.

- [ ] 와이파이에서 `node examples/live-weather-server/server.mjs` 가 실제로 밖에 나가는지 먼저

- [ ] 백업 Run 미리 만들기. 라이브가 막히면 Runs 목록에서 이 Run 을 연다.
  - Generate AI 완주 Run 1개 (§B-4 절차 그대로, 약 2분)
  - Repair 완주 Run 1개 (§B-5 절차 그대로)

- [ ] 홈 후보 목록에 `example-weather-server`·`example-live-weather-server`·`mcpeak-mock` 셋만

### A-3. Generate 화면

1. 사이드바 `Generate`. 1단계에 후보 카드 3장, 첫 카드 `example-weather-server` 가 이미 선택돼 있다.
2. `다음`. 2단계에 `server` / `server` / `examples/weather-server/server.suite.json` 이 차 있고
   힌트 `저장 위치의 파일명에서 뽑았습니다.` 가 보인다.
3. `다음`, `다음`. 4단계 맨 아래 「실행될 CLI 명령」:
   ```
   mcpeak generate --command node --arg examples/weather-server/server.mjs --suite-id server --name server --out examples/weather-server/server.suite.json --provider claude
   ```
4. 여기서 멈춘다. **생성 시작을 누르지 않는다** (AI 는 2분 걸린다).

### B-4. Generate AI 생성 (라이브)

1. `Generate`. 1단계에서 `HTTP URL` 눌러 목록이 비활성되고 힌트
   `원격 서버에 붙습니다. 위 서버 명령은 쓰이지 않습니다.` 가 붙는 것, `다음` 이 막히고
   `URL 을 입력하세요.` 가 뜨는 것을 3초 보여준 뒤 `stdio` 로 되돌린다.
2. `다음`. 2단계 저장 위치를 `.mcpeak/demo.suite.json` 으로 바꾼다. 스위트 ID·이름이 `demo` 로
   따라오는 것을 보여준다. `이미 있는 파일 덮어쓰기` 켠다.
3. `다음`. 3단계는 `AI가 테스트 케이스 작성` 그대로, 모델에 `sonnet`.
4. `다음`. 4단계 토글 두 개, 요약, CLI 전문. `생성 시작`.
5. Run 화면. 질문이 순서대로 온다. 전부 아래 버튼을 누른다.

| 순서 | 질문 | 누를 것 | 대사 |
|---|---|---|---|
| 1 | `이 요청을 전송할까요?` (Payload 981 bytes, 전송 데이터 목록) | `예` | 밖으로 나가는 건 전부 승인 화면. 뭘 몇 바이트 보내는지 보여준다 |
| 2 | `검토 메뉴` (`codex claude apply-all select revise edit save cancel`) | `save` | 버튼 이름이 CLI 메뉴 그대로다. save 가 "제안 반영하고 진행" |
| 3 | `계속할까요?` (시험 실행 8건 안내) | `예` | 실제 서버에 8건을 보낸다 |
| 4 | `나머지 6건의 진단을 AI 에게 요청할까요?` | `예` | 거절 케이스가 정말 거절인지 AI 가 판정 |
| 5 | `이 요청을 전송할까요?` (Payload 4259 bytes) | `예` | 실패 1건의 값 교정 요청 |
| 6 | `city: [서울]` 입력칸 | `제출` (기본값 그대로) | AI 제안값. 사람이 고칠 수 있다 |
| 7 | `최종 JSON을 저장할까요?` | `예` | |

6. `완료 · exit 0`. 로그 패널을 스크롤해 `get_weather.city: "example" → "서울"` 과
   `커버리지 2 tools, 8 axes 전부 검증` 을 보여준다.

편집 메모: 1번과 3번 뒤에 각각 20~40초 대기가 있다. 잘라낸다.

2. `repair 시작`. 폼에 모델 `sonnet`, `시작`.
3. Repair 화면. `보내시겠습니까?` → `예`.

### B-6. 외부 호출 녹화·재생 (CLI)

서버는 `examples/live-weather-server` (Open-Meteo·Frankfurter 를 `fetch` 로 부른다).

```bash
# 녹화. 실제 API 를 부른다
$MCPEAK test examples/live-weather-server/server.suite.json \
  --command node --arg examples/live-weather-server/server.mjs \
  --record-session .mcpeak/live-weather.session.json
```

기대 마지막 줄:

```
6 passed  (6 total)
→ 외부 호출 5건을 녹화했습니다: .mcpeak/live-weather.session.json
```

여기서 **와이파이를 끈다** (카메라에 잡히게). 그리고:

```bash
$MCPEAK test examples/live-weather-server/server.suite.json \
  --command node --arg examples/live-weather-server/server.mjs \
  --session .mcpeak/live-weather.session.json
```

기대 마지막 줄:

```
6 passed  (6 total)
→ 녹화된 외부 호출 5건을 재생했습니다: .mcpeak/live-weather.session.json (2026-08-25 07:25:01 UTC 녹화)
```

대사: 서버는 진짜로 뜨고, 서버가 밖에 부르는 호출만 녹화본에서 답한다. 같은 입력 같은 출력.
네트워크 없이 CI 에서 돈다.

와이파이 끄고 재생하는 장면은 **오늘 확인 안 됨** (녹화·재생은 네트워크 켠 채로 확인). 리허설에서
한 번 본다. 재생은 설계상 네트워크를 안 타지만(ADR-0057·0061) 눈으로 보고 넣는다.

## C. 막혔을 때

| 상황 | 대처 |

| Generate 1단계 첫 후보가 `.claude/worktrees/...` | worktree 가 남아 있다. §0 첫 항목 |

## D. 이 시나리오에서 말하지 않는 것

- AI 사전보완이 `미채택 2 (baseline 값이 이미 통과)` 라 한 직후 시험 실행에서 그 값이 실패하는
  장면이 B-4 에 있다. 결국 교정돼 저장되므로 흐름은 되지만, 질문이 들어오면 "사전보완은 값 형식
  검사, 시험 실행은 실제 응답 검사" 로 답한다. generate 패키지 몫이라 이번 PR 범위 밖.
- 검토 메뉴 버튼이 영문 그대로인 것, 로그 자동 스크롤이 없는 것은 dashboard 후속 PR 대상이다.
