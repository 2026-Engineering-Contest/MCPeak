## Claude 에 물을 것 (1:10 장면)

정의 파일에 있는 응답 둘만 성공한다. 서버 이름을 붙여 `lenstest` 의 동명 툴로 새지 않게 한다.

```
mcpeak-mock 의 get_weather 로 서울 날씨 알려줘        → { "city": "서울", "tempC": 21 }
mcpeak-mock 의 add 로 1 더하기 2 계산해줘              → { "sum": 3 }
```

"부산 날씨" 는 서울 값이 나오고(도시 무시), "3 더하기 4" 는 도구 오류. 묻지 않는다.
