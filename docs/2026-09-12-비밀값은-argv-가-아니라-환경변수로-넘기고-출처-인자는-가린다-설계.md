# 비밀값은 argv 가 아니라 환경변수로 넘기고, 출처 인자는 가린다 (2026-09-12)

관측: `docs/2026-09-11-공개서버-직접조작-데모-실측-문제.md` §3, 그리고 2026-09-12 Supabase
실측(이 문서 §1.2).
참조: ADR-0070(원격 서버의 인증 헤더는 값이 아니라 환경변수 이름으로 받는다),
ADR-0085(세션은 자기를 재생할 명령을 담는다), ADR-0039 · ADR-0045(민감 키 목록과 접미 단어열
매칭), ADR-0041(마스킹은 경계에서 적용한다), ADR-0053(Authorization 헤더 마스킹),
ADR-0013(CLI 는 `process` 를 직접 읽지 않는다).

기준 커밋 `d015a7d`.

## 1. 배경

### 1.1 지금 코드가 하는 일

stdio 서버는 `core` 가 띄운다. 자식 환경은 SDK 의 고정 허용 목록에 `options.env` 를 얹은
것이다(`packages/core/src/controlled-stdio.ts:80`).

```ts
const environment = { ...getDefaultEnvironment(), ...this.options.env };
```

허용 목록은 POSIX 에서 `HOME` · `LOGNAME` · `PATH` · `SHELL` · `TERM` · `USER` 여섯이다.
그 밖의 환경변수는 자식에게 가지 않는다. `options.env` 를 채우는 자리는 하나뿐이다.
External 배선이 만든 Bootstrap 주입 변수다(`packages/cli/src/external-wiring.ts`).
**사용자가 자식에게 환경변수를 넘길 방법은 CLI 에도 대시보드에도 없다.**

그래서 API 키가 필요한 서버를 붙이는 방법은 둘로 좁혀진다. 서버가 인자로 키를 받으면
`--arg --access-token --arg <값>` 이고, 환경변수로만 받으면 `--command env --arg KEY=값 --arg
node --arg …` 래퍼다. 둘 다 키가 **프로세스 argv 에 실린다.** 실측 §3 은 이것이 `ps` 와 셸
히스토리에 남는다는 이유로 권장 경로에서 뺐다.

한편 ADR-0085 는 녹화 시작 시 실행 명령을 세션에 저장한다. `sessions` 테이블의
`command` · `args_json` · `suite_path` 다. `args_json` 은 `--arg` 로 받은 값을 **원문 그대로**
담는다(`packages/record/src/external/session-store-sqlite.ts:362`).

### 1.2 실측: 토큰이 카세트에 남는다

`@supabase/mcp-server-supabase@0.12.0` 을 `--read-only` · `--project-ref` 고정으로 붙여 전체
흐름(generate → test + 녹화 → replay → determinism)을 돌렸다. 흐름은 성립했고 도구가 서버
결함도 찾았다. 그런데 녹화본을 열어 보니 이렇다.

```
sessions.args_json:
["-y","@supabase/mcp-server-supabase@0.12.0","--read-only","--project-ref","nyyf…",
 "--access-token","<PAT 원문>"]
```

`Authorization` 헤더는 ADR-0053 대로 가려졌다. 요청·응답 본문의 민감 키도 가려졌다. **그런데
실행 명령 자체가 토큰을 들고 있었고, 그 자리는 마스킹 대상이 아니었다.** 카세트는 저장소에
커밋하라고 만든 파일이다. 이 경로는 곧 저장소에 토큰이 들어가는 경로다.

같은 값이 셋에 남았다. 대화 기록, `ps`, 그리고 스크래치 카세트. 실측에 쓴 토큰은 폐기했다.

### 1.3 왜 지금 고치나

ADR-0070 은 원격 서버의 헤더 값에 대해 이미 같은 판단을 했다. "명령줄에 쓴 토큰은 `ps` 목록과
셸 히스토리에 남는다. 값은 환경변수에, argv 에는 이름만." 그 결정이 stdio 서버에는 적용되지
않았다. stdio 에는 값을 넘길 다른 통로가 없어서 사용자는 결국 argv 에 싣게 되고, 우리는 그
argv 를 커밋용 파일에 저장한다. **안전한 길이 없으면 경고는 아무것도 막지 못한다.** ADR-0070
이 B안을 버린 이유 그대로다.

데모 서버로 Supabase 를 쓰기로 했다. 그 데모는 관객 앞에서 녹화본을 열어 보이는 흐름을
가진다. 토큰이 든 카세트로는 그 장면을 만들 수 없다.

## 2. 목표와 완료 조건

**목표.** 비밀값이 argv 를 지나지 않는 통로를 만들고, 그래도 argv 로 들어온 비밀값은
세션에 저장되기 전에 가린다.

| # | 완료 조건 | 판정 방법 |
|---|---|---|
| 1 | `mcpeak test` · `mcpeak generate` 가 `--env <NAME>` 으로 부모 환경변수를 자식에게 이름으로 넘긴다. 값은 argv 에 없다 | 신규 E2E. 자식이 그 변수를 읽어 응답한다 |
| 2 | `--env` 에 이름이 아닌 것(값·`=`·공백)을 넣으면 거절하고, 왜 이름만 받는지 말한다 | 파서 유닛 |
| 3 | 가리키는 환경변수가 비어 있으면 **이름만** 말하고 멈춘다 | 파서·연결 유닛 |
| 4 | 대시보드가 `.mcp.json` 의 `env` 를 자식에게 넘긴다. 값은 브라우저와 argv 를 지나지 않는다 | 서버 유닛(`readEnv` 해석), 웹 유닛(argv 에 이름만) |
| 5 | 녹화 출처 `args` 에 든 비밀 모양의 값이 `[redacted]` 로 저장된다 | record 유닛(규칙 전량) + 엔진 유닛 |
| 6 | 가려진 출처로는 원클릭 재생을 하지 않고, 무엇이 가려졌고 어떻게 하라는지 말한다 | 웹 유닛(ReplayView) |
| 7 | 대시보드가 녹화 출처를 브라우저 `localStorage` 에 새로 적지 않는다(읽기 폴백은 유지) | 웹 유닛(Home) |

## 3. 비범위

- **`--env NAME=VALUE` 형식.** 값을 argv 에 싣는 형식이다. ADR-0070 이 평문 `--header` 를 두지
  않은 것과 같은 이유로 두지 않는다.
- **`.env` 파일 읽기.** 그것은 셸의 일이다(`direnv`, `dotenv`). 우리가 파일을 읽기 시작하면
  어느 파일을 어느 우선순위로 읽는지가 새 사양이 된다.
- **`.mcp.json` 의 `${VAR:-default}` 문법.** `${VAR}` 만 해석한다. 기본값 문법은 필요가
  나타나면 그때 연다.
- **자식 프로세스 자신의 argv 노출.** Supabase 서버가 `--access-token` 을 받는 것은 그 서버의
  설계다. 우리는 그 값을 우리 argv 와 우리 파일에 싣지 않는 것까지만 한다.
- **HTTP 요청·응답 본문의 마스킹 규칙 변경.** ADR-0039 · 0045 의 목록과 매칭은 그대로 쓴다.
  여기서 새로 만드는 것은 argv 라는 **다른 모양의 입력**에 그 목록을 적용하는 규칙이다.
- **민감 키 목록 스냅샷 version 상향.** 출처 인자 마스킹은 matchKey 에 영향이 없다. 목록에
  단어를 더하지 않는다.
- **`repair` 서브커맨드.** 서버를 띄우지 않으므로 `--env` 가 필요 없다.

## 4. 결정

### 4.1 결정 1: `--env <NAME>` 은 이름만 받고, 값은 `readEnv` 로 읽어 자식 환경에 얹는다

`mcpeak test` 와 `mcpeak generate` 에 `--env <NAME>` 을 더한다. 반복 가능하다. 이름은
`--header-env` 와 같은 정규식(`^[A-Za-z_][A-Za-z0-9_]*$`)으로 검사한다. 값은 CLI 가
`process.env` 를 직접 읽지 않고(ADR-0013) 이미 있는 `readEnv` 주입점으로 읽는다.

자식 환경은 세 겹이다. 순서가 계약이다.

```
SDK 기본 허용 목록  <  --env 로 넘긴 것  <  External 배선이 만든 것
```

External 배선(`MCPEAK_*`, `NODE_OPTIONS`)이 마지막에 얹힌다. 배선 변수가 사용자 값에 덮이면
녹화가 조용히 꺼진다. 그래서 `--env` 는 `MCPEAK_` 접두 이름과 `NODE_OPTIONS` 를 **거절**한다.
`NODE_OPTIONS` 는 배선이 부모의 것을 이미 이어 붙이므로(ADR-0095) 넘길 이유도 없다.

`--env` 는 `--url` 과 함께 쓸 수 없다. `--arg` 와 같은 이유다. 띄울 프로세스가 없다.

**`.mcp.json` 형식과의 대응.** 그 파일의 `env` 는 `{ "KEY": "값" }` 이고, Claude Code 는 값
자리의 `${VAR}` 를 확장한다. 우리 CLI 는 그 파일을 읽지 않는다. 대시보드가 읽고, 결정 3 의
방식으로 CLI 에 넘긴다.

### 4.2 결정 2: 실패 문장은 값을 싣지 않고, 이유와 올바른 예시를 준다

ADR-0070 의 문안 원칙을 그대로 따른다. **환경변수 이름 자리에 값을 넣은 사용자에게 형식만
말하지 않는다.** 왜 이렇게 받는지와 예시를 함께 준다. 예시는 `read -rs` 다.
`SUPABASE_ACCESS_TOKEN=… mcpeak …` 한 줄은 히스토리에 토큰째로 남으므로 예시로 쓰지 않는다.

### 4.3 결정 3: 대시보드는 `.mcp.json` 의 `env` 를 **이름은 argv 로, 값은 서버 프로세스 안에서** 넘긴다

대시보드의 계약은 "웹이 만든 argv 배열을 서버가 가공 없이 `runCli` 에 넘긴다" 다
(`packages/dashboard/web/src/build-test-argv.ts`). 이 계약을 지키면서 값을 브라우저에 보내지
않으려면 둘로 나눠야 한다.

- **서버 후보(`ServerCandidate`)는 `env` 의 키 이름 목록만 싣는다.** `hasEnv: boolean` 을
  `envNames: readonly string[]` 로 바꾼다. 값은 API 응답에 실리지 않는다.
- **웹은 고른 후보의 `envNames` 마다 `--env <NAME>` 을 argv 에 넣는다.** 그리고 실행 요청에
  후보 id(`serverId`)를 함께 보낸다.
- **서버는 그 run 의 `readEnv` 를 후보의 `env` 로 먼저 해석하고, 없으면 `process.env` 를 본다.**
  `.mcp.json` 값의 `${VAR}` 는 서버 프로세스의 `process.env` 로 확장한다. 확장할 값이 없으면
  `undefined` 를 돌려주고, 그러면 CLI 의 결정 2 문장("환경변수 `X` 가 비어 있습니다")이 그대로
  나온다. 대시보드가 문장을 따로 만들지 않는다.

`.mcp.json` 은 사용자 디스크의 파일이고 그 값은 서버 프로세스 안에서만 산다. 브라우저에도,
argv 에도, 세션 파일에도 실리지 않는다.

`ServerPicker` 의 "env 는 대시보드가 넘기지 못합니다. 셸에서 미리 내보내세요." 는 실측 §3 이
"따를 수 없는 지시" 로 판정한 문장이다. 지운다. 대신 후보에 env 가 있으면 어떤 이름을
넘기는지 보여준다.

### 4.4 결정 4: 녹화 출처의 `args` 는 저장 직전에 가린다

`createRecordEngine` 이 `store.createSession` 을 부르기 전에 `redactOriginArgs` 를 적용한다.
Store 두 구현(memory · sqlite)이 공유하는 유일한 진입이 엔진이라 여기가 한 자리다. Store 는
받은 값을 그대로 저장하는 계약을 유지한다.

가리는 규칙은 넷이다. 순서대로 적용하고, 하나라도 걸리면 그 토큰은 `[redacted]` 다. 자리표시
문자열은 `runtime.mjs` 가 헤더·쿼리에 쓰는 것과 같다.

| # | 모양 | 판정 | 예 |
|---|---|---|---|
| R1 | `--flag=value` · `-flag=value` | flag 이름이 민감 키(ADR-0039 접미 단어열)이면 `=` 뒤를 가린다 | `--access-token=sbp_…` → `--access-token=[redacted]` |
| R2 | `--flag` 다음 토큰 | flag 이름이 민감 키이면 **다음 토큰을** 가린다. 다음 토큰이 `-` 로 시작해도 가린다 | `--access-token sbp_…` → `--access-token [redacted]` |
| R3 | `NAME=value` | `NAME` 이 POSIX 환경변수 이름이고 민감 키이면 `=` 뒤를 가린다 | `env SUPABASE_ACCESS_TOKEN=… node` → `SUPABASE_ACCESS_TOKEN=[redacted]` |
| R4 | 단독 값 | 알려진 비밀 접두 + 최소 길이, 또는 JWT 모양이면 가린다 | `sbp_0123…` → `[redacted]` |

R1 · R2 · R3 은 **이름으로** 판정한다. 민감 키 목록과 매칭 함수(`sensitiveKeyIn`)를 그대로 쓴다.
`--access-token` 은 단어열 `[access, token]` 이라 `token` 에 걸리고, `--api-key` 는 `apikey` 에
걸린다. `--project-ref` 는 어디에도 안 걸린다. 데모에서 프로젝트 참조는 그대로 보여야 하고,
그래야 한다.

R4 는 **모양으로** 판정한다. 이름이 없는 자리(위치 인자, `env` 래퍼의 명령 뒤)를 위한
보루다. 오탐을 줄이기 위해 접두 일치에 최소 길이 20 을 건다. 접두 목록은 §5.3 에 전량 적는다.
목록 밖 비밀은 R4 가 못 잡는다. 그 한계는 ADR 의 §결과에 적는다. 그래서 R4 는 결정 1 의
대체가 아니라 안전망이다.

**R2 의 과잉 판정을 감수한다.** `--token` 이 값 없는 스위치인 서버에서는 그 다음 위치 인자가
가려진다. 그 결과는 원클릭 재생이 안 되고 입력 폼이 열리는 것이다(결정 5). 반대로 놓치면
토큰이 저장소에 들어간다. 비대칭이 크다.

### 4.5 결정 5: 가려진 출처는 원클릭 재생을 막고, 무엇을 하라는지 말한다

ReplayView 는 `origin.args` 에 `[redacted]` 가 하나라도 있으면 행을 펼친 상태로 두고 재생
버튼을 비활성으로 판정한다(`replayResult` 가 오류를 돌려준다). 문장은 이렇다.

```
녹화 때 인자 2개가 가려졌습니다([redacted]). 그 자리를 다시 채우거나,
서버가 환경변수를 받으면 그 값을 .mcp.json 의 env 로 옮기세요. env 는 argv 에 실리지 않아
가려지지 않습니다.
```

가려진 `[redacted]` 를 그대로 서버에 넘기면 서버는 "잘못된 토큰" 으로 실패하고, 사용자는 그
실패가 우리 마스킹 때문인지 서버 때문인지 알 수 없다. 막는 쪽이 낫다.

웹은 `@mcpeak/record` 를 import 하지 않는다(`api-types.ts` 가 `status` 를 다시 적는 것과 같은
이유). 자리표시 문자열 `[redacted]` 는 `web/src/session-origin.ts` 에 상수로 다시 적고, 그
사실을 양쪽 주석에 남긴다.

### 4.6 결정 6: 홈은 녹화 출처를 `localStorage` 에 새로 적지 않는다

`Home.tsx` 는 녹화 실행마다 `saveSessionOrigin` 으로 명령과 인자를 브라우저에 적어 둔다.
ADR-0085 가 "A안이 배포될 때까지의 과도기 폴백" 으로 남긴 자리다. 이제 모든 새 녹화는 v2
세션이라 출처가 파일에 있다. 브라우저에 다시 적으면 결정 4 가 가린 값이 **가려지지 않은
채로** 같은 기계의 다른 자리에 남는다. 쓰기를 지우고 읽기 폴백(`readSessionOrigin`)만 남긴다.
v1 세션은 그 폴백으로 지금처럼 보인다.

### 4.7 버린 선택지

**(A) 안내문만 고친다(실측 §3 의 (b)).** `command: "env"`, `args: ["KEY=값", …]` 래퍼를 화면이
시킨다. 실측 자체가 기각했다. 우리가 시키면 우리가 키를 흘리게 만드는 것이다.

**(B) 대시보드 실행 폼에 환경변수 값 입력란을 둔다(실측 §3 의 (c)).** 값이 브라우저와 API
요청 본문을 지난다. 로컬 서버라 전송 자체는 위험이 작지만, 값이 `lastRun` · `recentCommands`
같은 `localStorage` 경로로 새는 것을 막으려면 그 화면 전체를 다시 봐야 한다. 이름만 다루는
결정 3 이 더 작고 더 좁다.

**(C) `--env NAME=VALUE` 를 함께 준다.** ADR-0070 의 B안이다. 짧은 쪽이 기본이 되고 경고는
복사·붙여넣기를 막지 못한다.

**(D) 출처 `args` 를 통째로 저장하지 않는다.** ADR-0085 를 뒤집는다. 원클릭 재생이 사라진다.
비밀이 든 인자는 드물고 나머지 인자는 재생에 필요하다.

**(E) 출처 마스킹을 CLI 에서 한다(`externalModeOf`).** 대시보드도 CLI 를 지나므로 동작은
같다. 그러나 `SessionOrigin` 을 받아 저장하는 쪽이 record 고, "저장되는 값은 마스킹을 지났다"
는 보장은 저장하는 패키지가 들고 있어야 나중에 다른 호출자가 생겨도 유지된다. ADR-0041 이
마스킹을 경계에 두라고 한 그 경계가 여기서는 엔진이다.

**(F) `SessionOrigin` 에 `redactedIndexes` 같은 별도 필드를 둔다.** 저장 형식이 바뀌어
`SQLITE_STORE_VERSION` 이 3 이 된다. `[redacted]` 문자열 하나로 충분하고, 그 문자열이 실제
인자인 경우는 무시할 수 있을 만큼 드물다.

## 5. 계약 (전량)

### 5.1 CLI 옵션과 파서

`connect-target.ts` 에 `--header-env` 와 나란히 둔다. 두 커맨드가 같은 함수를 쓴다.

```ts
/**
 * `--env <NAME>` 값 하나를 검사한다. **이름만** 받는다. 값을 여기 넣으면 `ps` 와 셸
 * 히스토리와 녹화 출처에 그대로 남는다. 그것이 이 옵션이 이름만 받는 이유고, 거절 문장이
 * 그 이유를 말해야 한다.
 */
export function parseEnvForwardOption(raw: string): TargetResult<string> {
  const name = raw.trim();
  if (name === "") return err("`--env` 옵션 값이 필요합니다.");
  if (!ENV_NAME_PATTERN.test(name))
    return err(
      `\`--env\` 는 환경변수 **이름**만 받습니다: '${echoValue(raw)}'\n` +
        "→ 값을 명령줄에 쓰면 `ps` 목록과 셸 히스토리, 녹화 출처에 그대로 남기 때문입니다.\n" +
        "→ 값은 환경변수에 넣고 이름만 넘기세요:\n" +
        `${SECRET_ENV_EXAMPLE}\n` +
        "     mcpeak test suite.json --command npx --arg -y --arg <서버> --env SUPABASE_ACCESS_TOKEN",
    );
  if (name === "NODE_OPTIONS")
    return err(
      "`--env NODE_OPTIONS` 는 받지 않습니다.\n" +
        "→ 부모의 `NODE_OPTIONS` 는 녹화·재생 배선이 자식에게 이미 이어 붙입니다.",
    );
  if (name.startsWith("MCPEAK_"))
    return err(
      `\`--env ${name}\` 는 받지 않습니다.\n` +
        "→ `MCPEAK_` 로 시작하는 이름은 녹화·재생 배선이 자식 환경에 직접 씁니다. 사용자 값이 그것을 덮으면 녹화가 조용히 꺼집니다.",
    );
  return ok(name);
}
```

`SECRET_ENV_EXAMPLE` 은 `--header-env` 안내가 쓰는 `read -rs` 예시 상수다. 같은 것을 쓴다.

### 5.2 자식 환경 합성

`openConnection` 이 stdio 갈래에서 이름을 값으로 바꾼다.

```ts

  const env = { ...forwarded, ...options?.env };
```

`options.env`(External 배선)가 **뒤에** 온다. §4.1 의 순서다.

```ts
/**
 * 이름을 값으로 바꾼다. **비어 있으면 이름만 말한다.** 값이 비었다는 사실을 알리려다 값을
 * 화면에 찍으면 이 옵션이 존재하는 이유가 없어진다(ADR-0070 §3).
 */
function resolveForwardedEnv(
  names: readonly string[],
  readEnv: ConnectDependencies["readEnv"],
): Record<string, string> {
  if (names.length === 0) return {};
  if (readEnv === undefined)
    throw new ConnectTargetError(
      "이 진입점은 `--env` 를 지원하지 않습니다.\n" +
        "→ 환경변수를 읽는 주입점(readEnv)이 배선되지 않았습니다.",
    );
  const env: Record<string, string> = {};
  for (const name of names) {
    const value = readEnv(name);
    if (value === undefined || value === "")
      throw new ConnectTargetError(
        `환경변수 \`${name}\` 가 비어 있습니다.\n` +
          "→ 값을 넣고 다시 실행하세요:\n" +
          `${SECRET_ENV_EXAMPLE.replaceAll("MCP_TOKEN", name)}`,
      );
    env[name] = value;
  }
  return env;
}
```

`test-command.ts` 의 `openConnection` 호출 두 곳(1회차·`--determinism` 2회차)과
`generate-command.ts` 의 한 곳은 시그니처가 바뀌지 않는다. `target` 에 `envNames` 가 실리고
`readEnv` 가 이미 `connectDependencies` 에 들어 있으므로 호출부는 그대로다. `ConnectTargetError`
는 두 커맨드가 이미 사용 오류(`CLI_USAGE`)로 옮기는 경로가 있다.

### 5.3 출처 인자 마스킹 (`packages/record/src/external/origin-redaction.ts`, 신규)

```ts
import {
  LATEST_SENSITIVE_KEYS_VERSION,
  sensitiveKeyIn,
  sensitiveKeysOf,
} from "../shared/sensitive-keys.mjs";
import type { SessionOrigin } from "./session-store.js";

/** `runtime.mjs` 의 `REDACTED` 와 같은 문자열. 웹(`session-origin.ts`)이 다시 적는다. */
export const REDACTED_ARG = "[redacted]";

const ENV_NAME_PATTERN = /^[A-Za-z_][A-Za-z0-9_]*$/;
const FLAG_PATTERN = /^--?([A-Za-z][A-Za-z0-9_-]*)(=([\s\S]*))?$/;

/**
 * 이름 없는 자리의 보루. **접두 + 최소 길이**로 본다. 접두만 보면 `sk-` 같은 짧은 것이 일반
 * 단어에 걸린다. 목록 밖 비밀은 못 잡는다. 그래서 이것은 `--env` 의 대체가 아니라 안전망이다.
 *
 * 순서는 무관하다. 하나라도 맞으면 가린다.
 */
const SECRET_PREFIXES: readonly string[] = [
  "sbp_", // Supabase personal access token
  "sk-", // OpenAI · Anthropic(`sk-ant-`) 등
  "sk_live_", "sk_test_", "rk_live_", "rk_test_", // Stripe secret · restricted
  "ghp_", "gho_", "ghu_", "ghs_", "ghr_", "github_pat_", // GitHub
  "glpat-", // GitLab
  "xoxb-", "xoxp-", "xoxa-", "xoxr-", // Slack
  "AIza", // Google API key
  "AKIA", // AWS access key id
  "npm_", // npm
  "ntn_", "secret_", // Notion
  "hf_", // Hugging Face
  "tvly-", // Tavily
  "pypi-", // PyPI
  "dop_v1_", // DigitalOcean
  "gsk_", // Groq
  "xai-", // xAI
  "SG.", // SendGrid
];
const MIN_SECRET_LENGTH = 20;
/** header.payload.signature. 서명은 비어 있을 수 있다(alg=none). */
const JWT_PATTERN = /^eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]*$/;

const keys = sensitiveKeysOf(LATEST_SENSITIVE_KEYS_VERSION);

const looksLikeSecretValue = (value: string): boolean =>
  JWT_PATTERN.test(value) ||
  (value.length >= MIN_SECRET_LENGTH && SECRET_PREFIXES.some((prefix) => value.startsWith(prefix)));

/**
 * argv 한 줄에서 비밀 모양을 가린다. 규칙 넷(R1~R4)은 설계 §4.4 에 있다.
 *
 * **이름이 있으면 이름으로, 없으면 모양으로.** 이름 판정은 HTTP 헤더·JSON 키와 같은 민감 키
 * 목록과 같은 매칭이다. 목록이 늘면 여기도 같이 넓어지고, 따로 맞출 것이 없다.
 *
 * matchKey 와 무관하다. 출처는 재생의 재료일 뿐 매칭 입력이 아니므로, 여기서 무엇을 가려도
 * 이미 저장된 세션의 재생은 달라지지 않는다.
 */
export function redactOriginArgs(args: readonly string[]): readonly string[] {
  const out: string[] = [];
  let maskNext = false;
  for (const arg of args) {
    if (maskNext) {
      // R2. 스위치 다음 토큰은 `-` 로 시작해도 가린다. 놓치면 토큰이 저장소에 들어가고,
      // 과하게 가리면 원클릭 재생 대신 입력 폼이 열린다. 비대칭이 크다.
      out.push(REDACTED_ARG);
      maskNext = false;
      continue;
    }
    const flag = FLAG_PATTERN.exec(arg);
    if (flag !== null) {
      const [, name, withValue] = flag;
      if (sensitiveKeyIn(keys, name)) {
        if (withValue !== undefined) {
          out.push(`${arg.slice(0, arg.indexOf("="))}=${REDACTED_ARG}`); // R1
        } else {
          out.push(arg);
          maskNext = true; // R2
        }
        continue;
      }
      out.push(arg);
      continue;
    }
    const eq = arg.indexOf("=");
    if (eq > 0) {
      const name = arg.slice(0, eq);
      if (ENV_NAME_PATTERN.test(name) && sensitiveKeyIn(keys, name)) {
        out.push(`${name}=${REDACTED_ARG}`); // R3
        continue;
      }
    }
    out.push(looksLikeSecretValue(arg) ? REDACTED_ARG : arg); // R4
  }
  return Object.freeze(out);
}

export function redactOrigin(origin: SessionOrigin): SessionOrigin {
  return Object.freeze({ ...origin, args: redactOriginArgs(origin.args) });
}
```

`FLAG_PATTERN` 이 `-` 하나로 시작하는 짧은 플래그(`-t`)도 잡는다. `t` 는 민감 키가 아니라
안 걸린다. `-` 만 있는 토큰(stdin 관례)은 이름이 없어 패턴에 안 맞고 R4 로 간다.

`engine.ts`:

```ts
options.store.createSession(
  options.sessionId,
  options.origin === undefined ? undefined : redactOrigin(options.origin),
);
```

`session-store.ts` 의 `SessionOrigin.args` 주석에 한 줄을 더한다. "비밀 모양의 값은 엔진이
`[redacted]` 로 바꿔 넘긴다(ADR-0097). Store 는 받은 값을 그대로 저장한다."

## 7. 테스트 사양

### 7.1 CLI 파서 (`packages/cli/tests/test-command.test.ts`, `generate-command.test.ts`, `connect-target.test.ts`)

- `--env A --env B` 를 순서대로 `target.envNames` 에 모은다. `--env=A` 형식도 받는다.
- `--env A --env A` 는 `` `--env A` 이 두 번 있습니다. 한 번만 쓰세요. `` 로 거절한다.
- `--env 'A=b'`, `--env 'Bearer x'`, `--env ''` 는 거절 문장에 `환경변수 **이름**만 받습니다` 와
  `read -rs` 예시가 들어 있다. **거절 문장에 입력값 `b` · `x` 가 그대로 들어가지 않는다**는
  단언은 두지 않는다. 입력을 되짚는 것은 `echoValue` 로 이미 하고 있고, 그 값은 이름 자리에
  잘못 넣은 것이라 되짚어도 된다. 단언하는 것은 문장에 이유와 예시가 있다는 것이다.
- `--env NODE_OPTIONS` · `--env MCPEAK_X` 는 각자의 문장으로 거절한다.
- `--env A --url https://…` 는 `` `--env` 는 `--url` 과 함께 쓸 수 없습니다. `` 로 거절한다.
- `openConnection` 유닛: `readEnv` 가 `A` 를 `"1"` 로 주면 `connectStdio` 가 `env: { A: "1" }`
  를 받는다. `options.env` 에 `A: "wiring"` 이 있으면 **`wiring` 이 이긴다.** `readEnv` 가
  `undefined` 나 `""` 를 주면 `ConnectTargetError` 이고 문장에 `A` 가 있고 값이 없다. `readEnv`
  자체가 없으면 "이 진입점은 `--env` 를 지원하지 않습니다".

### 7.2 CLI E2E (`packages/cli/tests/env-forward-e2e.test.ts`, 신규)

## 8. 남는 갈래

- **R4 접두 목록 밖의 비밀.** 이름도 없고 접두도 없는 값은 못 가린다. `--env` 가 정답이고,
  R4 는 안전망이다. 목록에 없는 서비스에서 실제로 새는 사례가 나오면 접두를 더한다. 접두
  추가는 matchKey 와 무관해 version 상향 없이 할 수 있다.
- **셸 히스토리.** `--env` 는 우리 argv 를 깨끗하게 하지만, 사용자가 `export TOKEN=…` 을 셸에
  치면 그 줄은 히스토리에 남는다. 안내가 `read -rs` 를 쓰는 이유다. 우리가 통제할 수 없는
  자리라 ADR §결과에 적고 끝낸다.
- **`ps` 에 보이는 자식 자신의 argv.** Supabase 서버가 `--access-token` 을 받도록 설계된 것은
  그 서버의 일이다. `--env SUPABASE_ACCESS_TOKEN` 을 쓰면 그 자리도 비지만, 서버가 환경변수를
  안 받으면 남는다.
- **대시보드 `lastRun` · `recentCommands`.** 수동 입력 갈래에서 사용자가 인자에 토큰을 치면
  그 값이 `localStorage` 에 남는다. 결정 4 의 규칙을 웹에도 적용할지는 이 설계의 범위 밖이다.
  후보 갈래(`.mcp.json`)로 가면 값이 폼에 들어오지 않아 이 문제가 없다.
