# ADR-0012 CLI 기본 출력 전환

상태: 초안
날짜: 2026-08-13
관련 설계: `docs/superpowers/specs/2026-08-13-cli-report-rendering-design.md` §4, §11

## 배경

`ohmymcp test` 는 `RunnerReport` 를 들여쓰기된 JSON 으로 통째로 stdout 에 덤프했다. 응답 본문 단언
웨이브가 `$.temperature: 필수 필드가 없습니다. 발견된 필드: 'city', 'condition', 'temp'` 같은
문장을 완성해 두었지만, 사용자가 그것을 보려면 중괄호를 헤치고 들어가야 했다. 프로젝트 지침은
"실패 메시지가 곧 제품" 이라고 규정한다. 지금 제품 표면은 JSON 이었다.

기계용 출력을 없앨 수는 없다. `packages/cli/tests/dist-cli-e2e.mjs` 가 stdout 을 `JSON.parse` 로
판정하고, CI 에서 이 도구를 쓰는 사람도 같은 것을 한다. 무엇을 기본값으로 둘지의 문제다.

## 선택지

1. 기본 JSON 을 유지하고 사람용 출력을 `--reporter pretty` 같은 opt-in 으로 둔다.
2. 기본 JSON 을 유지하고 stdout 이 TTY 면 자동으로 사람용으로 바꾼다.
3. 기본을 사람용으로 바꾸고 기존 JSON 을 `--json` opt-in 으로 옮긴다.

## 결정

선택지 3을 택한다. `ohmymcp test` 의 기본 stdout 은 `renderReport` 결과이고, `--json` 을 붙이면
이전과 같은 바이트를 낸다. 종료 코드는 바뀌지 않는다. stderr 오류 경로도 그대로다.

`--json` 은 값을 받지 않는 불리언 플래그다. 중복 지정과 `--json=true` 형태를 거절한다.

## 이유

**선택지 1은 목적을 달성하지 못한다.** 진단 문장을 보려고 매번 플래그를 붙일 사람은 없다. 기본값이
곧 사람들이 보게 되는 것이다.

**선택지 2는 결정론성과 충돌한다.** 같은 명령이 실행 환경에 따라 다른 바이트를 낸다. 로컬에서는
사람용, CI 에서는 JSON 이 나오면 "같은 입력에 항상 같은 결과" 라는 프로젝트 핵심 가치가 깨지고,
파이프로 넘길 때와 터미널에서 볼 때의 동작이 달라 재현 보고가 어긋난다. 환경 판정은 색상 여부에만
쓴다. 그것은 바이트 구조가 아니라 장식이고, `--json` 경로에는 아예 들어가지 않는다.

**파괴적 변경 비용이 지금 가장 싸다.** npm 미배포 알파이고 stdout 을 파싱하는 소비자는 저장소 안의
테스트 셋뿐이다. `packages/cli/tests/dist-cli-e2e.mjs`, `packages/cli/tests/cli-integration.test.ts`,
`packages/cli/tests/generate-integration.test.ts` 이며 같은 웨이브에서 함께 고친다. 사용자가 생긴
뒤에 바꾸면 같은 결정이 훨씬 비싸진다.

**버전은 minor 로 올린다.** 출력 계약이 깨지므로 major 가 맞아 보이지만, 현재 `ohmymcp` 버전이
`0.2.0` 이라 major 는 `1.0.0` 이 된다. 그것은 우리가 아직 주장할 수 없는 안정성 선언이다. 파괴적
변경 사실은 changeset 본문에 명시한다.

## 결과

- 실패한 테스트의 진단 문장과 해결 힌트가 사용자 눈앞에 바로 온다.
- stdout 을 기계로 파싱하던 스크립트는 `ohmymcp test ... --json` 으로 바꿔야 한다. `--json` 출력
  바이트는 이전과 동일하므로 그 외의 수정은 필요 없다.
- `runCli` 는 여전히 `process` 를 읽지 않는다. 색상 판정은 `packages/cli/src/index.ts` 한 줄이
  하고, `runCli` 는 주입받은 `colorEnabled` 불리언을 `renderReport` 에 그대로 넘긴다. 덕분에 CLI
  테스트가 TTY 를 위장하지 않아도 색상 전달을 관찰할 수 있다.
- `renderReport` 를 의존성으로 주입한 결과 CLI 테스트가 렌더링 문안을 다시 단언하지 않는다. 문안은
  `packages/runner` 의 테스트가 고정한다.
