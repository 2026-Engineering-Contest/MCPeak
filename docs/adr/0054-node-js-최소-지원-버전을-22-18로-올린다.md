# ADR-0054: Node.js 최소 지원 버전을 22.18.0으로 올린다

- 상태: 채택
- 날짜: 2026-08-21
- 담당: 릴리스, 전체
- 작성자: @ddxng5
- 승인: 승인 (2026-08-21, 사용자)
- 관련: 이슈 #228, [ADR-0052](./0052-coordinator가-engine과-session-store를-소유한다.md)

## 배경

저장소는 루트 `engines.node`와 CI 매트릭스에서 Node 20을 지원한다고 명시해 왔다. 그러나 현재
빌드 도구 `tsdown@0.22.14`는 Node `^22.18.0 || >=24.11.0`을 요구해 빌드 잡을 이미 Node 22로
분리했다. 배포 패키지 7개에는 `engines.node`가 없어 사용자가 실제 지원 범위를 설치 전에 알 수도
없다.

External Record/Replay의 영속 Session Store는 Node 내장 `node:sqlite`를 사용할 예정이다.
`node:sqlite`는 Node 22.13부터 별도 실행 플래그 없이 사용할 수 있지만, 저장소 전체를 설치하고
빌드하는 실질 하한은 빌드 도구가 요구하는 22.18이다. 런타임과 개발 도구의 최소 버전을 다르게
표시하면 기여자가 지원된다고 적힌 환경에서 빌드에 실패할 수 있다.

## 선택지

- A안: Node 20 지원을 유지하고 SQLite 대신 파일 Store만 제공한다.
- B안: 런타임은 Node 22.13, 루트 개발 환경은 Node 22.18로 서로 다르게 선언한다.
- C안: 루트와 모든 배포 패키지의 최소 버전을 Node 22.18.0으로 통일한다.

## 결정

C안을 선택한다.

- 루트와 배포 패키지 7개의 `engines.node`를 `>=22.18.0`으로 선언한다.
- CI verify 매트릭스는 최소 버전 `22.18.0`과 Node 24를 검사한다. `22` 같은 이동 표적만 쓰지
  않고 선언한 최소 버전 자체를 반드시 포함한다.
- TypeScript 출력 기준은 ES2022로 유지한다. 최소 런타임 상향을 새 문법 도입이나 기존 코드
  리팩터링의 근거로 사용하지 않는다.
- pnpm, `@modelcontextprotocol/sdk`, 기존 Tool 카세트의 형식과 동작은 이 결정에서 바꾸지 않는다.
- Node 20 지원 종료는 배포 패키지 전부의 changeset에 기록한다.

## 이유

하나의 최소 버전이 사용자, 기여자, CI에 똑같이 보이는 편이 실패 원인을 분명하게 만든다. 22.13과
22.18을 나누면 설치는 성공하지만 빌드는 실패하는 구간이 생긴다. 22.18로 통일하면 현재 도구 체인과
향후 `node:sqlite`를 모두 추가 의존성 없이 사용할 수 있다.

현재 기존 소스는 Node 22 CI에서 이미 통과한다. 저장소에서 Node 버전으로 동작을 나누는 코드는
`mock` stdio 테스트의 Node 20 skip 한 곳뿐이며, 상향 뒤에는 해당 테스트가 모든 지원 런타임에서
실행된다. 따라서 이 결정의 위험은 비즈니스 로직 변경보다 배포 패키지의 지원 범위를 좁히는 데 있다.

## 결과

- Node 22.18.0 미만 사용자는 package manager의 engine 진단을 받는다.
- CI는 Node 22의 최신 패치에서만 우연히 성공하는 회귀를 막기 위해 22.18.0을 직접 검사한다.
- 배포 패키지 7개가 같은 런타임 계약을 가진다.
- Node 20 전용 테스트 skip과 그 설명을 제거한다.
- `node:sqlite` Session Store는 별도 기능 PR에서 `SessionStore` 계약 구현으로 추가한다. 이 ADR은
  SQLite 스키마, 저장 경로, 마이그레이션 정책을 결정하지 않는다.
- SQLite의 런타임 경고를 없애기 위해 프로세스의 전체 warning listener를 제거하지 않는다. 경고
  정책이 필요하면 SQLite 구현과 함께 별도로 결정한다.
  → [ADR-0056](./0056-node-sqlite-실험-경고를-external-사용자에게만-보인다.md)에서 결정했다.
  External을 실제로 쓸 때만 모듈을 불러 경고 범위를 좁히고, 그 이상 숨기지 않는다.
- 이 ADR 번호는 커밋·PR 전에 충돌 여부를 다시 확인한다.
