# ADR-0084: 홈은 서버부터 고르는 3단계 마법사다

- 상태: 제안
- 날짜: 2026-08-25
- 담당: dashboard
- 작성자: @seodduu (① MCP 서버 테스트 파트)
- 참조: `packages/dashboard/web/src/screens/Home.tsx`,
  `packages/dashboard/web/src/home/match-suites.ts`,
  `packages/dashboard/web/src/generate/suggest.ts`, ADR-0046, ADR-0079, ADR-0080

## 배경

홈은 스위트 목록이 먼저였다. 행마다 「실행」을 누르면 그 자리에서 폼이 펼쳐지고, 그 안에서
서버를 고르고 옵션을 정했다. 스위트가 여러 개인 프로젝트에서는 같은 서버를 스위트마다 다시
고르게 되고, 한 화면 안에 목록·폼·최근 실행이 겹쳐 무엇을 먼저 정해야 하는지가 안 보였다.

옆에 이미 Generate 4단계 마법사가 있다. 같은 프로젝트의 같은 서버를 한쪽에서는 카드로 고르고
다른 쪽에서는 목록 안 폼으로 고르면, 사용자는 그 차이를 기능 차이로 읽는다.

## 선택지

1. **서버 → 스위트 → 옵션 3단계 마법사.** Generate 와 같은 `Stepper`·같은 컴포넌트를 쓴다.
   2단계는 1단계에서 고른 서버의 스크립트 이름으로 스위트를 골라 위에 편다.
2. **지금 구조를 두고 폼만 정리.** 목록 행 안의 폼을 접이식 섹션으로 나눈다.
3. **스위트 → 서버 순서의 마법사.** 단계는 나누되 순서는 그대로 둔다.

## 결정

1번. 단계 라벨은 「테스트할 서버」·「테스트할 스위트」·「실행 옵션」이고, 우측 「최근 실행」
카드는 홈에서 뺀다(사이드바 Runs 가 같은 목록이다).

스위트 매칭은 `matchSuites` 한 곳이다. 서버 인자에서 스크립트를 찾아 확장자를 벗긴 접두사로
`<접두사>.suite*.json` 과 `<접두사>.json` 을 고른다. generate 의 `suggestOutPathFor` 를 거꾸로
읽은 것이고, 확장자 표는 그쪽과 같은 값을 쓴다.

곁따라 두 가지를 옮겼다.

- **접속 방식(stdio/HTTP)이 테스트 옵션에서 1단계로 올라간다.** 1단계는 명령이 비면 통과할 수
  없는데, 접속이 3단계에 있으면 HTTP 사용자는 1단계를 통과할 방법이 없다.
- **「지난 실행」 서버 갈래가 1단계에서 빠진다.** 지난 실행값은 스위트 경로를 키로 저장되는데
  스위트는 2단계에서 고른다. 대신 2단계에서 스위트를 고를 때 그 스위트의 지난 옵션을 3단계
  기본값으로 채우고, 지난 실행 서버가 지금 고른 것과 다르면 3단계에 한 줄로 알리며
  「지난 실행값 쓰기」로 되돌릴 수 있게 둔다.

## 이유

**스위트를 정하는 것은 서버다.** generate 가 서버 스크립트 옆에 `.suite.json` 을 두므로
(ADR-0080 이전부터의 규칙), 서버를 알면 스위트를 되짚을 수 있다. 역방향은 성립하지 않는다.
스위트 파일에는 어느 서버로 돌릴지가 안 적혀 있어서, 스위트를 먼저 고르면 서버는 매번 다시
정해야 한다.

2번은 겹침은 줄지만 순서 문제가 남는다. 3번은 매칭을 쓸 수 없어 단계를 나눈 값이 작다.

매칭은 필터가 아니라 정렬이다. 나머지 스위트는 「다른 스위트 보기」로 접어 두고, 매칭이
0건이면 처음부터 펴 둔다. 규칙이 못 맞히는 이름(스크립트를 옮겼거나 손으로 만든 스위트)을
목록에서 빼 버리면 그 사용자는 실행할 방법이 없다.

## 결과

- `Home.tsx` 는 마법사 껍데기(상태·단계 검증·`startRun`)만 남고, 단계 본문은
  `home/steps/StepRunServer`·`StepRunSuite`·`StepRunOptions` 로 나뉜다.
- `TestOptionsPanel` 에서 「접속」 그룹이 빠진다. 이 패널을 쓰는 곳은 홈뿐이다.
- argv 계약은 그대로다. `buildTestArgv` 와 서버 라우트는 손대지 않았다.
- `matchSuites` 와 `suggestOutPathFor` 의 확장자 표가 갈리면 generate 가 방금 만든 스위트를
  홈이 못 찾는다. 두 파일의 주석이 서로를 가리키고, 각자의 테스트가 같은 확장자 표를 단언한다.
- 홈에서 최근 실행을 보던 사람은 사이드바 Runs 로 가야 한다.
