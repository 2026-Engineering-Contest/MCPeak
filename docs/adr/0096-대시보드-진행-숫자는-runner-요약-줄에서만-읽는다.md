# ADR-0096: 대시보드 진행 숫자는 runner 요약 줄에서만 읽는다

- 상태: 제안
- 날짜: 2026-09-12
- 작성자: ddxng5
- 관련: ADR-0046(대시보드를 로컬 웹서버로 만든다) · ADR-0072(실행 상태는 summary 1회 + SSE 로 안다) · ADR-0093 · 이슈 #459

## 배경

#459 의 실행 화면 시안은 진행 카드(원형 %, "3 of 10 test cases completed", 막대, 통과 ·
실패 · 남은 수)를 둔다. 그런데 대시보드는 **실행 중에 케이스별 진행을 알 방법이 없다.**

- `mcpeak test` 는 보고서를 모았다가 끝에 한 번 쓴다(`web/src/output-lines.ts` 주석). 실행 내내
  SSE 이벤트가 0건일 수 있다(ADR-0072).
- `RunEvent` 에는 stdout/stderr html · question · done 뿐이고, 진행 이벤트는 없다.
- 끝에 오는 보고서에는 runner 가 형식을 고정한 요약 줄 `2 passed, 1 failed  (3 total)` 이 있다
  (`packages/runner/src/reporter.ts` 의 `SUMMARY_LABELS`, `reporter.test.ts` 가 문자열로 고정).

## 선택지

- **A안 — 시안대로 진행률을 그린다.** 실행 중 숫자는 추정하거나 0 으로 둔다.
- **B안 — CLI 가 구조화된 진행 이벤트를 내게 한다.** `RunEventInput` 에 `progress` 를 더하고
  cli 가 케이스마다 내보낸다.
- **C안 — 진행률은 그리지 않고, 끝나면 요약 줄을 읽어 통과 · 실패 · 미실행 세 칸만 채운다.**
  web 이 출력 평문에서 마지막 요약 줄을 찾는다.
- **D안 — 상태 단계만 그린다.** 실행 → 입력 대기 → 끝. 숫자는 없다.

## 결정

**C안.** `parseRunTally()`(`web/src/run-tally.ts`)가 출력 평문의 **마지막** 요약 줄만 읽고,
항목 합이 total 과 다르거나 모르는 낱말이 끼면 null 을 낸다. null 인 동안 세 칸은 `—` 다. 요약
줄을 내지 않는 흐름(generate · repair)은 세 칸을 그리지 않는다.

처음 구현은 실행 중 비율 없이 흐르는 막대(불확정)를 두었다가 **뺐다**(#459 리뷰). 막대는 실행 중에
"돌고 있다" 밖에 말하지 못하는데 그것은 상태 뱃지가 이미 말하고, 끝나면 한 번에 차서 새로 알려
주는 것이 없었다. 그 높이는 터미널에 돌려주는 편이 낫다.

## 이유

- **A안은 결정론과 정직성을 둘 다 깬다.** 추정한 숫자는 같은 run 을 다시 열 때마다 달라질 수
  있고, "0건 통과" 는 모르는 것을 아는 척하는 문장이다(#295 와 같은 원칙).
- **B안이 바른 끝 상태지만 이 이슈의 범위가 아니다.** cli · runner 의 출력 경로와 `RunEventInput`
  (dashboard 서버 타입)을 함께 바꿔야 해 한 번에 한 패키지 규칙을 넘는다. C안은 B안이 들어와도
  버릴 것이 없다 — 진행 이벤트가 오면 세 칸을 실행 중에도 채우고, 그때 진행률 표시를 다시 논의한다.
- **D안은 이미 알고 있는 숫자를 버린다.** 끝난 run 의 통과 · 실패 수는 출력에 확실히 있다.
- C안이 새로 만드는 결합은 **요약 줄 한 줄의 형식**뿐이다. 그 형식은 runner 가 설계 문서
  §5.6 과 테스트로 고정한 값이고, 바뀌어도 화면은 틀린 숫자가 아니라 "요약 없음" 으로 떨어진다.

## 결과

- web 이 runner 의 사람용 출력 한 줄에 기댄다. `SUMMARY_LABELS` 의 낱말이 바뀌면
  `run-tally.ts` 의 표도 같이 고쳐야 한다(web 은 runner 를 import 하지 않으므로 값을 옮겨 적었다).
- 실행 중 진행률은 여전히 없다. 필요해지면 B안을 별도 이슈로 연다.
- 시안의 경과 시간 · 시작 시각은 넣지 않았다. `RunSummary` 에 필드가 필요하고 시계를 읽어야
  하므로 #459 가 범위에서 뺀 항목이다.
