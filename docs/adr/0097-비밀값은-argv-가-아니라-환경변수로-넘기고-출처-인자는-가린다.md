## 배경

stdio 서버의 자식 환경은 SDK 의 고정 허용 목록에 External 배선이 만든 변수를 얹은 것뿐이다.
사용자가 자식에게 환경변수를 넘길 통로는 CLI 에도 대시보드에도 없다. 그래서 API 키가 필요한
서버를 붙이는 길은 `--arg <값>` 이거나 `--command env --arg KEY=값` 래퍼이고, 둘 다 키가 우리
프로세스의 argv 에 실린다. 실측 문서 §3 이 이 경로를 권장에서 뺀 이유가 그것이다. 한편
ADR-0085 는 녹화 시작 시 실행 명령을 세션에 저장하고, `args_json` 은 `--arg` 값을 원문 그대로
담는다. 2026-09-12 Supabase 실측에서 그 두 사실이 만났다. 전체 흐름은 성립했지만 녹화본의
`args_json` 에 개인 접근 토큰이 평문으로 들어 있었다. 카세트는 저장소에 커밋하라고 만든
파일이므로, 이 경로는 곧 저장소에 토큰이 들어가는 경로다. 실측에 쓴 토큰은 폐기했다.

## 선택지

1. **`--env <NAME>` 통로 + 출처 인자 마스킹.** (채택) 값이 argv 를 지나지 않는 길을 열고,
   그래도 argv 로 들어온 값은 세션에 저장되기 전에 가린다.
2. **(A) 안내문만 고친다.** `env` 래퍼를 화면이 시킨다. 실측이 이미 기각했다. 우리가 시키면
   우리가 키를 흘리게 만드는 것이다.
3. **(B) 대시보드 실행 폼에 환경변수 값 입력란을 둔다.** 값이 브라우저와 API 요청 본문을
   지난다. `lastRun` · `recentCommands` 같은 `localStorage` 경로로 새는 것을 막으려면 그 화면
   전체를 다시 봐야 한다. 이름만 다루는 결정 3 이 더 작고 더 좁다.
4. **(C) `--env NAME=VALUE` 를 함께 준다.** ADR-0070 의 B안이다. 짧은 쪽이 기본이 되고 경고는
   복사·붙여넣기를 막지 못한다.
5. **(D) 출처 `args` 를 통째로 저장하지 않는다.** ADR-0085 를 뒤집고 원클릭 재생을 없앤다.
   비밀이 든 인자는 드물고 나머지 인자는 재생에 필요하다.
6. **(E) 출처 마스킹을 CLI 에서 한다.** 동작은 같지만 "저장되는 값은 마스킹을 지났다" 는
   보장이 저장하는 패키지 밖에 놓인다.
7. **(F) `SessionOrigin` 에 `redactedIndexes` 같은 필드를 둔다.** 저장 형식이 바뀌어
   `SQLITE_STORE_VERSION` 이 3 이 된다. 자리표시 문자열 하나로 충분하다.

## 결정

**1. `--env <NAME>` 은 이름만 받는다.** `mcpeak test` 와 `mcpeak generate` 에 반복 가능한
`--env` 를 더한다. 이름은 `--header-env` 와 같은 정규식으로 검사하고, 값은 CLI 가 `process` 를
직접 읽지 않고 `readEnv` 주입점으로 읽는다(ADR-0013). `--url` 과는 함께 쓸 수 없다. 자식 환경
합성 순서가 계약이다.

```
SDK 기본 허용 목록  <  --env 로 넘긴 것  <  External 배선이 만든 것
```

배선 변수가 사용자 값에 덮이면 녹화가 조용히 꺼지므로 `--env` 는 `MCPEAK_` 접두 이름과
`NODE_OPTIONS` 를 거절한다.

**2. 실패 문장은 값을 싣지 않는다.** 형식만 말하지 않고 왜 이름만 받는지와 `read -rs` 예시를
함께 준다. 가리키는 환경변수가 비어 있으면 이름만 말하고 멈춘다.

**3. 대시보드는 이름을 argv 로, 값을 서버 프로세스 안에서 넘긴다.** `ServerCandidate` 의
`hasEnv` 를 `envNames` 로 바꾸고, 웹은 이름마다 `--env <NAME>` 을 넣고 후보 id 를 함께 보낸다.
서버는 그 run 의 `readEnv` 를 후보의 `env` 로 먼저 해석하며 `${VAR}` 확장도 서버 안에서 한다.
`.mcp.json` 의 값은 브라우저에도 argv 에도 세션 파일에도 실리지 않는다.

**4. 녹화 출처의 `args` 는 저장 직전에 가린다.** `createRecordEngine` 이 `store.createSession`
앞에서 `redactOriginArgs` 를 적용한다. Store 는 받은 값을 그대로 저장하는 계약을 유지한다.
규칙은 넷이고 순서대로 적용하며, 하나라도 걸리면 그 토큰은 `[redacted]` 다.

| # | 모양 | 판정 | 예 |
|---|---|---|---|
| R1 | `--flag=value` · `-flag=value` | flag 이름이 민감 키(ADR-0039 접미 단어열)이면 `=` 뒤를 가린다 | `--access-token=sbp_…` → `--access-token=[redacted]` |
| R2 | `--flag` 다음 토큰 | flag 이름이 민감 키이면 **다음 토큰을** 가린다. 다음 토큰이 `-` 로 시작해도 가린다 | `--access-token sbp_…` → `--access-token [redacted]` |
| R3 | `NAME=value` | `NAME` 이 POSIX 환경변수 이름이고 민감 키이면 `=` 뒤를 가린다 | `env SUPABASE_ACCESS_TOKEN=… node` → `SUPABASE_ACCESS_TOKEN=[redacted]` |
| R4 | 단독 값 | 알려진 비밀 접두 + 최소 길이, 또는 JWT 모양이면 가린다 | `sbp_0123…` → `[redacted]` |

R1 · R2 · R3 은 이름으로 판정하고 민감 키 목록과 `sensitiveKeyIn` 을 그대로 쓴다. `--project-ref`
는 어디에도 걸리지 않으며, 데모에서 프로젝트 참조는 그대로 보여야 한다. R4 는 모양으로
판정하는 보루이고 접두 일치에 최소 길이 20 을 건다.

**5. 가려진 출처는 원클릭 재생을 막는다.** `origin.args` 에 `[redacted]` 가 하나라도 있으면
ReplayView 는 행을 펼친 채 두고 재생을 거절하며, 무엇이 가려졌고 그 자리를 어떻게 채우는지를
말한다. 웹은 `@mcpeak/record` 를 import 하지 않으므로 자리표시 문자열은 상수로 다시 적고 그
사실을 양쪽 주석에 남긴다.

**6. 홈은 녹화 출처를 `localStorage` 에 새로 적지 않는다.** 모든 새 녹화는 v2 세션이라 출처가
파일에 있다. 쓰기를 지우고 읽기 폴백만 남긴다. v1 세션은 그 폴백으로 지금처럼 보인다.

## 이유

ADR-0070 이 B안을 버린 논리가 stdio 에도 그대로 적용된다. 안전한 경로를 더해도 위험한 경로를
남겨 두면 짧고 익숙한 쪽이 기본이 되고, 문서의 경고는 복사·붙여넣기를 막지 못한다. stdio 는
거기서 한 발 더 나갔다. 값을 넘길 안전한 통로가 아예 없었으므로 사용자는 결국 argv 에 싣게
되고, 우리는 그 argv 를 커밋용 파일에 저장했다. 안전한 길이 없으면 경고는 아무것도 막지
못한다.

마스킹을 엔진에 두는 것은 ADR-0041 이 정한 경계를 이 입력 모양에 옮긴 것이다. Store 두
구현이 공유하는 유일한 진입이 엔진이라 여기가 한 자리이고, "저장되는 값은 마스킹을 지났다" 는
보장을 저장하는 패키지가 들고 있어야 나중에 다른 호출자가 생겨도 유지된다.

R2 의 과잉 판정은 감수한다. `--token` 이 값 없는 스위치인 서버에서는 그 다음 위치 인자가
가려지고, 그 결과는 원클릭 재생 대신 입력 폼이 열리는 것이다. 반대로 놓치면 토큰이 저장소에
들어간다. 두 결과의 비대칭이 크다.

## 결과

- **사용자 표면이 셋 바뀐다.** CLI 에 `--env <NAME>` 이 생기고, 대시보드의 "env 는 대시보드가
  넘기지 못합니다" 안내가 어떤 이름을 넘기는지 보여주는 표시로 바뀌며, 가려진 출처의 세션은
  재생 버튼 대신 입력 폼과 설명을 연다.
- **남는 갈래 넷.** R4 접두 목록 밖의 비밀은 못 가린다(`--env` 가 정답이고 R4 는 안전망이다).
  사용자가 셸에 `export TOKEN=…` 을 치면 그 줄은 히스토리에 남는다(안내가 `read -rs` 를 쓰는
  이유다). 서버가 환경변수를 받지 않으면 자식 자신의 argv 에는 값이 남는다. 대시보드의 수동
  입력 갈래는 `lastRun` · `recentCommands` 에 값이 남을 수 있고, 후보 갈래로 가면 값이 폼에
  들어오지 않아 이 문제가 없다.
- **되돌리는 조건.** `--env` 만으로 실제 사용이 막히는 사례가 나오면 값 형식을 다시 논의한다.
  근거는 "편해서" 가 아니라 이름만으로는 값을 줄 수 없는 실제 실행 형태여야 한다.
