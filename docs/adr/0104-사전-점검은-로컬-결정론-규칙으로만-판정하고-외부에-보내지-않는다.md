# ADR-0104: 사전 점검은 로컬 결정론 규칙으로만 판정하고 외부에 보내지 않는다

- 상태: 제안
- 날짜: 2026-10-03
- 담당: audit
- 작성자: @seodduu
- 참조: `docs/plans/2026-10-03-audit-핵심-검사-구현계획.md`, `docs/2026-10-03-mcp-보안-테스트-도구-시장조사.md`,
  `docs/2026-10-03-audit-검사-목록-보강-검토.md` §5, `docs/benchmark/mcp-audit-recall/RESULTS.md`

## 배경

`mcpeak audit` 는 MCP 서버를 쓰기 전에 도구 정의·실행 명령·프로토콜 응답을 읽고 위험을 알린다.
판정을 어디서 무엇으로 할지가 첫 갈림길이다. 시장의 상위 도구는 판정을 클라우드나 LLM 에 맡긴다.
그러면 사용자의 도구 정의와 서버 구성이 밖으로 나가고, 같은 서버를 두 번 점검해도 결과가 같다는
보장이 없다. 이 저장소는 결정론을 핵심 가치로 두고, 녹화·재생과 CI 게이트가 그것에 기대고 있다.

## 선택지

1. **로컬 결정론 규칙(정규식·코드포인트 표·스키마 검사·표면 해시)만으로 판정한다. 외부 전송 없음.** (채택)
2. snyk/agent-scan 방식. tools/list 를 받아 서버 이름·설정 경로·도구 목록을 판정 API 로 보내고
   점수를 받는다. 기각. 판정 로직이 서버 쪽이라 무엇으로 걸렸는지 볼 수 없고, 오프라인 모드가 없으며,
   사용자 도구 정의가 제3자에게 간다. 같은 입력에 같은 결과도 보장되지 않는다.
3. Cisco mcp-scanner 방식. 로컬 YARA 규칙에 LLM·클라우드 분석기를 선택으로 얹는다. 기각(부분 차용).
   YARA 문형의 질은 높아 `desc/covert-action` 의 출처로 삼았다(Apache-2.0). 그러나 LLM 분석기는
   결정론을 깨고, 의존성(litellm·tree-sitter 10종·yara-python)이 무거워 Node 패키지에 들일 수 없다.
4. mcpward 방식. 로컬 정규식과 lockfile 드리프트까지는 같고, 검사 대상 서버를 호스트 env 그대로
   띄운다. 기각(부분 차용). 규칙 모양과 드리프트 해시는 따랐지만, 비밀을 서버에 넘기는 부분은
   ADR-0105 가 바꾼다.

## 결정

- 모든 판정은 `@mcpeak/audit` 안의 순수 함수로 한다. 네트워크는 HTTP 대상 자신에 대한 프로토콜
  프로브(`protocol/*`)에만 쓰고, 그 밖의 곳으로는 아무것도 보내지 않는다.
- 같은 입력이면 `--json` 출력이 바이트까지 같다. 정렬·중복 제거 순서를 고정하고, 시각·PID·카나리
  값을 출력에 쓰지 않는다. 판정할 수 없는 프로브는 "확인 안 함" 발견으로 남겨 두 실행의 차이를 보이게 한다.
- 리포트 끝에 "바꿔 말한 지시와 서버 코드의 실제 행위는 보지 못한다" 를 항상 적는다.

## 이유

점검 도구가 사용자 정보를 밖으로 보내면 점검 대상과 같은 종류의 위험을 스스로 만든다. 결정론이 있어야
CI 에서 기준선을 걸 수 있고, 발견 하나하나가 어느 문형에 걸렸는지 근거(`evidence`)로 설명된다.
재현율이 낮다는 대가는 숨기지 않고 측정해 기록한다.

## 결과

- MCPTox 1,312 사례에서 첫 실측 탐지율은 36.1% 다(`RESULTS.md`). 탐지의 거의 전부가 `<IMPORTANT>`
  태그에서 나오고, "Ignore the previous instructions" 와 "when using the 'X' tool, you MUST …" 는 문형의
  빈틈 때문에 거의 걸리지 않는다. 이 빈틈은 규칙 수정으로 메울 수 있는 것이라 결정론 원칙과 충돌하지
  않는다. 반면 패러프레이즈를 놓치는 것은 이 결정의 예상된 비용이며, 행위 관측(단계 2, Docker 격리)이
  그 몫이다.
- 규칙을 넓히면 정상 서버 오탐이 는다. `examples/` 전부와 영어 정상 모양 픽스처의 "발견 0" 이 넓힐 때의
  하한 조건이다.
- LLM 판정은 이후에도 선택 기능으로만 검토하고, 기본 판정과 종료 코드에는 넣지 않는다.
