# ADR-0108: 격리 흔적 줄이기와 안팎 표면 비교는 회피를 어렵게 할 뿐이라 지속 감시로 넘긴다

## 배경

격리 안에서 서버를 띄워 행위를 보는 검사는, 서버가 격리를 알아채고 얌전히 굴면 아무것도 보지 못한다.
컨테이너에는 흔적이 남는다. `/.dockerenv` 파일, cgroup 경로, 비어 있는 홈, 무작위 호스트 이름이다. 로드맵은
이 흔적을 지우라고 했다. 그런데 지울 수 있는 것과 없는 것이 갈리고, 다 지워도 "열 번째 호출부터" 나 "설치
일주일 뒤부터" 달라지는 서버는 한 번의 실행으로 잡을 수 없다.

## 선택지

1. **일반 `docker run` 으로 되는 만큼만 줄인다(고정된 그럴듯한 호스트 이름, 미끼 자격 증명으로 채운 홈).
   지우지 못한 흔적은 리포트에 한계로 적는다. `--compare-host` 가 이 머신에서 서버를 한 번 더 띄워
   `tools/list` 만 받고, 격리 안의 도구 표면과 다르면 `surface/environment-dependent`(high)로 알린다. 시간이
   지나야 드러나는 행동은 `--baseline` 비교를 이어 가는 것으로 넘긴다.** (채택)
2. 특권 컨테이너(`--privileged` 또는 `CAP_SYS_ADMIN`)로 cgroup 을 다시 마운트하고 `/.dockerenv` 를 가린다.
   기각. 격리를 약하게 해서 위장을 얻는 것이다. 점검 대상은 신뢰하지 않는 코드이고, 그 코드가 특권을 가진
   컨테이너에서 돈다.
3. 마이크로 VM(Firecracker, gVisor)으로 띄운다. 보류. 컨테이너 흔적은 사라지지만 Linux 와 KVM 이 전제라
   macOS·Windows 의 Docker Desktop 사용자가 쓸 수 없고, VM 에도 VM 의 흔적이 있다. 백엔드 인터페이스
   (`SandboxBackend`) 뒤에 자리만 둔다.
4. 흔적을 그대로 두고 아무것도 하지 않는다. 기각. 가장 값싼 회피(`/.dockerenv` 가 있으면 다른 도구 설명을
   낸다)를 잡을 길이 있는데 쓰지 않는 것이다.

## 결정

- 격리 홈은 실제 사용자의 홈처럼 보이는 파일(클라우드·편집기·패키지 관리자의 자격 증명 자리)로 채우고 값은
  형식만 닮은 무작위 문자열이다. 파일에는 미끼라는 표식을 붙이지 않는다. 호스트 이름은 고정된 평범한
  이름이다.
- `/.dockerenv` 와 cgroup 경로는 감추지 않는다. 격리가 켜진 리포트의 꼬리가 그 사실을 적고, `--compare-host`
  를 주지 않았으면 그 옵션을 권한다.
- `--compare-host` 는 기본으로 꺼져 있다. 켜면 서버가 **이 머신에서 격리 없이** 한 번 뜬다. 도구는 호출하지
  않지만 서버의 시작 코드는 실행된다. 도움말과 README 가 이 점을 말한다. 띄우지 못하면 발견이 아니라
  "검사하지 않은 것" 에 사유를 적는다.
- 비교가 같아도 리포트는 "호출 뒤의 행동까지 같다는 뜻은 아닙니다" 라고 적는다.

## 이유

흔적을 얼마나 줄이든 회피를 없애지는 못한다. 값을 올릴 뿐이다. 그렇다면 격리를 약하게 만드는 위장보다, 가장
흔한 회피를 직접 잡는 비교와 한계를 숨기지 않는 리포트가 낫다. 안팎 표면 비교는 결정론적이다(두 `tools/list`
의 정규화된 해시 비교). 사전 점검은 피해를 0 으로 만드는 도구가 아니라, 조용히 몇 달 갈 일을 첫 시도에서
드러내는 도구다. 나머지는 등록한 뒤에도 표면을 계속 비교하는 쪽(`--baseline`)이 맡는다.

## 결과

- `examples/sandbox-target-server` 는 `/.dockerenv` 가 있으면 `ping` 의 설명을 다르게 낸다. E2E 가
  `--sandbox --compare-host` 에서 그 한 건이 `surface/environment-dependent` 로 잡히는 것을 고정한다.
- `--compare-host` 는 격리의 보호를 한 번 벗어난다. 시작하자마자 해를 끼치는 서버에는 쓰면 안 된다. 그래서
  기본이 아니고, 격리 안의 결과를 먼저 본 뒤 켜는 옵션이다.
- 격리를 알아채는 방법은 표면 말고도 많다(호출 응답만 바꾸기, 시각·호출 횟수 조건). 이 검사는 그것을 보지
  못하고 리포트 꼬리가 그렇게 적는다.
- 더 강한 격리가 필요해지면 `SandboxBackend` 의 다른 구현으로 끼운다. CLI 와 규칙은 바뀌지 않는다.
