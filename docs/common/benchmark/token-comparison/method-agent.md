## 방법

MCPeak 의 에이전트용 파이프라인으로 검증한다. MCP 클라이언트를 직접 작성하지 마라. 이 디렉터리의
`mcpeak-agent.mjs` 가 명세 생성, 실행, 자리값 보완, 재실행, 보고서 작성을 한 번에 한다.

### 1. 명령 하나를 실행한다

```bash
node mcpeak-agent.mjs --report report.md -- node ./server.mjs
```

끝나면 요약이 찍힌다. 케이스 수, 결함 목록(도구·케이스·서버 오류), 적용한 픽스처, 보고서 경로.
`report.md` 는 보고 형식대로 이미 작성돼 있다.

### 2. 요약을 읽고 보고서를 제출한다

요약의 결함 목록이 곧 결과다. `report.md` 를 열어 보고 형식과 맞는지 확인하고, 틀린 곳이 있을 때만
고쳐라. 명세 파일이나 서버 소스를 다시 읽을 필요는 없다. 결함이 0건이면 그렇게 보고한다.
