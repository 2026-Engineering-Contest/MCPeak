# 대시보드 Generate 서버 선택과 단계 재배치 구현계획 (2026-08-25)

참조 문서: `docs/2026-08-25-대시보드-generate-서버-선택-설계.md`(이하 "설계"), ADR-0081,
`docs/2026-08-25-대시보드-홈-실행-폼-설계.md`(홈 설계, `ServerPicker`·접속 블록의 원본),
ADR-0079, `docs/2026-08-19-대시보드-UI-설계.md`(토큰·공용 컴포넌트).

> **실행 방식:** 터미널 세션은 오케스트레이터이며 태스크마다 서브에이전트를 스폰해 구현시키고
> 사이사이 리뷰한다(테스트 통과 + 파일 소유권 준수 + 설계 §6 계약 일치). 직접 구현하지 않는다.

## 1. 목표 / 비범위 / 완료 조건

**목표** (설계 §2 그대로)

1. Generate 1단계는 서버를 고르기만 하면 된다. 홈의 `ServerPicker` 가 맨 위, 직접 입력은
   마지막 갈래다.
2. 후보를 고르면 2단계의 저장 위치·스위트 ID·이름이 자동으로 찬다. 사용자가 고친 값은
   덮어쓰지 않는다.
3. 단계를 속성 성격으로 다시 묶는다. 3단계 = 생성 방식(mode/provider/model),
   4단계 = 검증과 확인(dryRun/repair/resetCmd + 요약 + CLI 전문).
4. `--url`·`--header-env` 를 1단계 접속 방식으로 노출하고 generate 배선에
   `connectHttp`·`readEnv` 를 넣는다.
5. stdio 갈래의 argv 는 한 토큰도 바뀌지 않는다.

**비범위** (설계 §3 그대로): 한 화면 폼 전환, 후보 갈래의 인자 편집, 지난 생성 갈래,
`.mcp.json` `env` 주입, 서버 후보 API 변경, `dashboard` 밖 패키지 수정.

**완료 조건**

- `pnpm --filter @mcpeak/dashboard test` 전부 통과. `pnpm typecheck --force` 통과하며
  `Cached: 0 cached`. `pnpm lint` 통과.
- 설계 §6 의 타입·argv 순서·거절 문장·제안 규칙이 한 글자도 다르지 않다.
- `build-argv.test.ts` 의 **기존 케이스**가 입력 객체에 `transport: "stdio", url: "",
  headerEnvs: []` 를 더한 것 외에 수정 없이 통과한다(목표 5 의 증거).
- `test-options-panel.test.tsx`·`home.test.tsx` 가 **수정 없이** 통과한다(`TransportFields`
  추출이 홈을 바꾸지 않았다는 증거).
- G3 시각 점검 체크리스트(라이트·다크, 1~4단계, 후보 있음/없음/HTTP)가 보고서에 있다.

`GET /api/meta`(`{root: "/repo"}`), `POST /api/runs` 에 응답한다.

- `generate-wizard.test.tsx` (기존 7건은 단계 이름·위치만 바꿔 유지. `fillStepServer` 는

  - `후보를 고르고 완주하면 후보의 command·args 가 --command/--arg 로 POST 된다`
    (후보 `{command:"node", args:["examples/weather-server/server.mjs"]}` → argv 선두
    `["--command","node","--arg","examples/weather-server/server.mjs","--suite-id","server","--name","server","--out","examples/weather-server/server.suite.json"]`)
  - `후보 선택 시 2단계 저장 위치·스위트 ID·이름이 제안돼 있고 힌트가 붙는다`
  - `사용자가 고친 스위트 ID 는 서버를 바꿔도 유지된다`
  - `저장 위치를 고치면 제안값이던 스위트 ID·이름이 새 파일명으로 따라온다`
  - `직접 입력을 고르면 StepServer 가 펼쳐지고 스크립트 경로 기준 제안이 그대로다`
  - `후보 0 이면 안내 상자와 직접 입력이 펼쳐진 채 시작한다`
  - `HTTP 를 고르면 후보 목록이 비활성이고 URL 없이는 다음이 막힌다` (사유 문구
    `URL 을 입력하세요.`)
  - `HTTP 로 완주하면 --url 과 --header-env 가 POST 되고 --command 가 없다`
  - `3단계에 시험 실행·자동 교정 토글이 없고 4단계에 있다`
  - `4단계에서 시험 실행을 끄면 초기화 입력이 비활성이고 값이 비워진다`
  - `4단계 요약의 실행 명령 행이 HTTP 면 원격 URL 을 보여준다`
  - `직접 입력 갈래에서만 최근 명령이 저장된다`
