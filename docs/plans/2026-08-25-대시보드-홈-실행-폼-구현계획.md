# 대시보드 홈 실행 폼 구현계획 (2026-08-25)

참조 문서: `docs/2026-08-25-대시보드-홈-실행-폼-설계.md`(이하 "설계"), ADR-0079,
`docs/2026-08-19-대시보드-UI-설계.md`(토큰·공용 컴포넌트), 목업
`docs/mockups/2026-08-25-홈-실행-폼/home-server-picker.html`.

> **실행 방식:** 터미널 세션은 오케스트레이터이며 태스크마다 서브에이전트를 스폰해 구현시키고
> 사이사이 리뷰한다(테스트 통과 + 파일 소유권 준수). 직접 구현하지 않는다.

## 1. 목표 / 비범위 / 완료 조건

**목표** (설계 §2 그대로)

1. 홈 `실행` 은 서버를 고르기만 하면 된다. 후보는 `GET /api/servers`(신설)와 브라우저의
   지난 실행값, 마지막 갈래가 직접 입력이다.
2. `mcpeak test` 옵션(`--json` 제외)을 접이식 섹션의 GUI 컨트롤로 노출한다.
3. CLI 가 거절하는 조합은 폼에서 만들 수 없다. 판정은 `buildTestArgv` 하나다.
4. 기본값 폼의 argv 는 지금과 바이트 단위로 같다.

**비범위** (설계 §3 그대로): Generate 마법사 후보 목록, 스위트 JSON 변경, 서버 이력 argv,
`--help` 파싱, `--json`, `.mcp.json` `env` 주입, `examples/weather-server` 에 `.mcp.json`
두기(후속 작업), 실서버 E2E.

**완료 조건**

- `pnpm --filter @mcpeak/dashboard test` 전부 통과. `pnpm typecheck --force` 통과하며
  `Cached: 0 cached`.
- `pnpm lint` 통과.
- 설계 §6 의 계약(타입·argv 순서·거절 문장·저장 키)이 한 글자도 다르지 않다.
- H4 시각 점검 체크리스트(라이트·다크, 화면 1~4 상태)가 보고서에 있다.
- `build-test-argv.test.ts` 의 기존 케이스가 **수정 없이** 통과한다(목표 4 의 증거).

### Task H3 — Home 화면

모델: **상위**. 사유: 빈 후보 안내·조합 제약 힌트·조립 실패 사유가 곧 이 화면의 실패
메시지이고(`CLAUDE.local.md` 모델 표의 예외 1), 설계 §5 문장을 그대로 쓰되 컴포넌트
분할과 비활성 전파는 계획에 코드로 못 박기 어렵다.

사양: 설계 §5 전부, §6-6.

- `ArgChips`: `StepServer` 의 인자 칩 블록을 컴포넌트로 뽑는다. props
  `{ idPrefix, args, disabled?, hint?, onChange }`. `StepServer` 는 이것을 쓴다.
- `ServerPicker`: props `{ candidates, lastRun, choice, onChoose, disabled?, disabledHint?,
  root }`. 라디오 카드 목록(§5-2), 빈 상태 안내(§5-2 문장).
- `TestOptionsPanel`: props `{ options, sessionMode, open, onToggle, onChange }`. 접이식
  머리줄 요약(`기본값 · 바꾼 것 없음` / `N개 바꿈`), 세 묶음(§5-5). `N` 은
  `DEFAULT_TEST_OPTIONS` 와 다른 키의 수다(`headerEnvs` 는 길이 0 과 비교).
- `Home.tsx`: 버튼 `실행`/`닫기` 전환(`aria-expanded`), 초기 선택 규칙(§6-6), 미리보기
  문자열(§5-6, 공백 든 토큰 큰따옴표), 시작 후 `saveLastRun`·`saveRecentCommand`(§5-7).
- `StepServer` 힌트 `직접 입력하거나 최근 사용값에서 고릅니다(프로젝트 스캔 API 없음).` 을
  `직접 입력하거나 최근 사용값에서 고릅니다.` 로 바꾼다.

테스트 케이스 (전량):

- `server-picker.test.tsx`
  - `후보가 name·명령 전문·출처 배지와 함께 라디오로 그려진다`
  - `hasEnv 후보에 env 안내 문장이 붙는다`
  - `지난 실행이 있으면 첫 항목이고 배지가 "이 브라우저" 다`
  - `후보 0·지난 실행 없음이면 root 를 담은 안내가 나오고 라디오가 없다`
  - `root 가 null 이면 경로 없이 안내가 나온다`
  - `disabled 면 모든 라디오가 비활성이고 disabledHint 가 보인다`
- `test-options-panel.test.tsx`
  - `접힌 상태에서 요약이 "기본값 · 바꾼 것 없음" 이다`
  - `determinism 과 junit 을 바꾸면 요약이 "2개 바꿈" 이다`
  - `HTTP 를 고르면 URL·헤더 입력이 나타나고 stderr 줄 수가 비활성이다`
  - `세션이 켜져 있으면 결정론 검사가 비활성이고 힌트가 보인다`
- `home.test.tsx` (기존 3건 유지, 아래 추가. fetch 스텁에 `/api/servers` 갈래 추가)
  - `실행을 누르면 버튼이 닫기로 바뀌고 다시 누르면 폼이 닫힌다`
  - `첫 후보가 자동 선택되고 미리보기가 mcpeak test 로 시작하는 전문이다`
  - `후보를 고르면 인자 칩이 채워지고 칩을 지우면 argv 에서 빠진다`
  - `직접 입력을 고르면 StepServer 가 펼쳐지고 서버 스크립트 라벨이 보인다`
  - `후보가 없으면 안내가 나오고 직접 입력이 펼쳐져 있다`
  - `옵션에서 결정론 검사를 켜면 POST argv 에 --determinism 이 들어간다`
  - `HTTP 를 고르면 POST argv 가 --url 로 시작하고 --command 가 없다`
  - `실행 시작 후 지난 실행값이 저장되고 다시 열면 그 값이 선택돼 있다`
  - `지난 실행이 스캔 후보와 같으면 지난 실행 항목이 없고 그 후보가 선택된다`
  - `조립 실패 사유가 미리보기 자리에 나오고 시작 버튼이 비활성이다`
