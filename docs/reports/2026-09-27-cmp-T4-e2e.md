## 실행한 명령

```sh
cli() { node packages/cli/dist/cli.mjs "$@"; }
cli test examples/weather-server/server.broken-demo.suite.json \
  --command node --arg examples/weather-server/server.broken-demo.mjs          # 2회, --json 2회
cli test <손 명세> --command node --arg examples/weather-server/server.mjs      # 2회
cli test <손 명세> --command node --arg examples/weather-server/server.broken-demo.mjs
cli generate --suite-id zod-notes --name "Zod Notes" --out <notes 명세> \
  --command node --arg examples/zod-notes-server/server.mjs --baseline-only
cli test <notes 명세> --command node --arg examples/zod-notes-server/server.mjs
cli test <notes 명세> --command node --arg examples/zod-notes-server/server.mutant.mjs  # 2회, --json 2회
```

손 명세는 설계 §2.2 의 B1(필드 이름), B2(값 하나), 값 둘, B6(`add` 에서 `b` 누락 거절 기대)
네 케이스다.

주의: zsh 에서 `CLI="node …"; $CLI test …` 로 부르면 단어가 쪼개지지 않아 명령이 안 돈다. 이때
두 출력이 같은 오류 문장이라 `cmp` 가 "같음" 을 낸다. 첫 측정에서 이 거짓 신호를 밟았고, 셸 함수로
바꿔 다시 쟀다. 위 결과는 다시 잰 것이다.
