1. **`read_note` 의 노트 디렉터리를 홈 아래(`~/notes`)로 잡았다.** 계획서는 "`notes/` 아래" 라고만 한다. 서버

## 남은 위험

- 위 "막힌 곳" 이 풀리기 전에는 audit 와 cli 의 타입체크가 빨강이다.
- `0600` 이 Linux 에서 안 읽힌다는 가정은 CI 에서 처음 확인된다(실측 5).
- 예제의 발견 수 여섯은 관측으로만 뒷받침된다. 규칙 본문과 게이트웨이가 생긴 뒤 T6 의 E2E 가 처음으로 센다.
- `Location` 의 `call` 갈래는 `audit.ts` 의 `orderedLocation` 에서 `default` 로 빠져 `callId`·`toolIndex` 를
  잃는다. 타입 오류는 아니라서 조용하다. §5.1 끝 문단대로 T5 가 고쳐야 한다.
- `allowJs` 를 켜고 `sandbox` 를 include 했다. `checkJs` 는 켜지 않았으므로 게이트웨이 `.mjs` 는 타입 검사를
  받지 않는다.
