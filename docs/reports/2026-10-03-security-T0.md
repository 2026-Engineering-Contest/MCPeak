## 임의로 판단한 부분

- 숨은 문자 확인을 `grep -nP` 대신 `perl -ne` 로 했다. macOS grep 에 `-P` 가 없기 때문이다.
- 테스트 파일을 처음 썼을 때 쓰기 도구가 이스케이프를 실제 U+200B, U+202E 로 바꿔 저장했다. `perl -pi` 로 그 바이트를 역슬래시 이스케이프 표기로 되돌린 뒤 다시 확인했다.
- §7.1 의 첫 테스트는 `import * as audit` 로, 나머지는 같은 `../src/index.js` 에서 이름으로 import 해 썼다. 공개 면(index)을 거치는지를 모든 테스트가 확인하게 하려는 것이다.
- §7.1 의 마지막 항목(renderReport 출력 불변)은 계획서대로 이 파일에서 단언하지 않고 기존 report 테스트 실행으로 확인했다.
- 이 보고서 파일은 허용 Files 목록에 없지만 위임 지시에 경로가 명시돼 있어 썼다.
