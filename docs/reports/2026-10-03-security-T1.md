## 임의로 판단한 부분

- 셋째 테스트의 단언 방향을 `expect(index.nodeAuditDependencies).toBe(commands.nodeAuditDependencies)` 로 적었다.
  계획서는 동일성만 요구하고 어느 쪽이 기대값인지는 정하지 않았다.
- 지시에 없는 확인 하나를 더했다. 빌드 산출물을 `node` 로 실제 불러 ESM 과 CJS 양쪽에서 이름이 함수로
  나오는지 봤다. 파일은 바꾸지 않았다.

## 남은 위험

- `commands.ts` 가 이제 `index.ts` 를 끌어온다. `index.ts` 는 import 만으로는 아무것도 실행하지 않지만
  (진입점은 `cli.ts`), 앞으로 `index.ts` 에 최상위 부수효과가 생기면 `@mcpeak/cli/commands` 를 쓰는 대시보드에도
  그대로 실린다. 빌드 산출물에서는 이미 `commands.mjs` 와 `index.mjs` 가 같은 공유 청크(`src-*.mjs`)를 읽고
  있어 번들 크기 변화는 사실상 없다.
