### Tailwind 로 옮기며 목업과 달라진 점

- 반응형 경계가 760px 이 아니라 Tailwind `md`(768px) 다. 토큰을 새로 만들지 않았다(계획 §4.4 가 예고).
- 선택 카드의 아래 화살표(`::after`)는 뺐다. 선택은 `aria-selected` 와 `border-accent ring-1 ring-accent` 로 보인다.
- 성능 카드 빗금은 계획의 `repeating-linear-gradient(135deg, var(--line-subtle) 0 6px, transparent 6px 12px)` 그대로이고
  목업의 12px/2px 줄무늬와 다르다. `opacity-75`·`cursor-not-allowed` 는 목업을 따랐다.
- 비용 막대는 목업처럼 원본·압축 두 줄이되 옆의 바이트 라벨("7,384 B")은 없다(계획이 뺐다). 보안 막대의 칸 사이 `gap-0.5`.
- 배지·칩·눈썹 글자 크기는 목업의 px 값 대신 Tailwind 단계(`text-xs`, `text-[11px]`)를 썼다. 막대 폭은 `toFixed(1)` 백분율이다.
- 접힌 바의 서버 칸은 고정 글자 "직접 입력"(출처 꼬리 없음), 명령 칸은 `truncate` + `font-mono`.
- §4.4 의 "목업에서 빼는 것" 목록(마지막 분석 시각, 소스 반영 가능 칩, 호출 1,000회당 절감, 성능 예시 칩, 기준 파일 갱신 후 재점검,
  오버레이 저장, exit 표기, 상세 머리의 토글·요약 띠, 안내문 등)은 구현하지 않았다.
