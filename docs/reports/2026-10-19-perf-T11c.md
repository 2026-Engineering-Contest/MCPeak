## 변경

`packages/perf/src/child/preload.mjs`

- 로드 시점 값 `responseClone` 을 `loadTimeClone` 으로 이름을 바꾸고, `currentClone()` 을 더했다. 부를 때마다
  `globalThis.Response?.prototype?.clone` 을 읽어 함수면 그것, 아니면 `loadTimeClone` 을 돌려준다.
- `dressAs` 의 `clone` 이 `Reflect.apply(currentClone(), this, [])` 로 복제하고, 결과가 객체면 같은 `dressAs` 를 적용한다.
  `dressAs` 가 던지면(덮은 clone 이 얼린 객체 등을 돌려준 경우) 삼키고 그 값을 그대로 돌려준다. 프로토타입 clone 이 던지는
  오류는 서버에게 그대로 간다.
- 다른 동작(통과 스트림, cancel, 배압, tEnd, seq, undici, 열거·headers)은 건드리지 않았다.

`packages/perf/tests/fixtures/preload-child.mjs`: 모드 `patched-clone`. 자식 코드 첫머리(프리로드 뒤)에서
`Response.prototype.clone` 을 호출 수를 세는 함수로 덮고, `/redirect` 를 fetch 해 `res.clone()` 한 번 뒤 `calls`, url·redirected·
type, 복제본의 셋, 두 갈래 본문을 JSON 으로 낸다.

`packages/perf/tests/preload-e2e.test.ts`: 항목 `"감싼 응답의 clone 은 호출 시점의 Response.prototype.clone 을 따른다"`. 프리로드
쪽 `calls` 가 1, 복제본의 url·type 이 원본과 같고 redirected 가 true, 프리로드 유무 두 JSON 이 같다, 프리로드 쪽 추적에 fetch
start 줄이 있다.

## 임의로 판단한 것

1. **덮은 clone 의 결과가 객체일 때만 dressAs 하고, 실패는 삼킨다.** 라이브러리가 얼린 객체나 Response 가 아닌 값을
   돌려줘도 원본 응답에서처럼 그 값이 서버에게 가야 하기 때문이다. 관측 코드의 예외를 삼키는 프리로드 원칙과 같다.
2. **대비값 조건은 "함수가 아니면".** 사양 문장 그대로다. `Response` 자체가 사라진 경우도 같은 대비로 간다.

## 남은 위험

1. 프리로드 뒤에 덮은 clone 이 안에서 `this.clone()` 을 다시 부르면 감싼 응답의 own `clone` 으로 들어가 무한 재귀가 된다.
   프리로드 없는 원본에서도 같은 코드는 무한 재귀이므로 동작 차이는 아니다.
2. 설계 §4.3 의 알려진 차이(`getOwnPropertyNames` 에 다섯 속성, 프로토타입 getter·clone 을 직접 `call` 하면 원본 값을 못 봄)는
   그대로 남는다.
